

**一、属性选择器（本模块主角）**

1. **`~=` 按"词"匹配。** `span[class~="sr-only"]` 能选中 `class="sr-only year"`，因为 class 值被空格切成两个词，其中一个完整等于 sr-only。换成 `=` 就选不中了。

2. **`.total` 不等于 `[class="total"]`。** `.total` 实际等价于 `[class~="total"]`。本项目里 `tr[class="total"]` 和 `tr.total` 效果一样，只是因为那行 class 恰好只有一个词；哪天多加一个 class，`=` 那条立刻失效。fCC 故意两种写法混用，就是让你看出这个区别。

3. **`[class]` 只看有没有。** `#years span[class]` 不关心值是什么，有 class 属性就选。

**二、无障碍：两条反方向的轨道**

4. **sr-only：眼睛看不见，读屏能念。** 和 `display: none` 不同，后者连读屏也听不到。几个关键属性：`position: absolute` 脱离文档流不占位，宽高 1px 加 `overflow: hidden` 缩成一个点，`clip` 和 `clip-path` 一旧一新并写是为了兼容，`white-space: nowrap` 防止文字在 1px 宽里每个词折一行，导致有些读屏软件把词粘在一起念。全加 `!important` 是因为这个类的意图就是"无论如何都要藏住"，不能被别的规则覆盖。

5. **aria-hidden：眼睛看得见，读屏跳过。** 顶部年份条只给眼睛看，每张表 thead 里的 sr-only 年份只给耳朵听。两套信息各走各路，读屏不会把年份念两遍。

6. **表格语义。** `caption` 是表名，`thead`/`tbody` 分区，`tbody` 里每行开头用 `th` 当行标题，左上角空格子用 `td` 占位。

**三、定位：直接复用今天冷启动的两题**

7. **caption 往上提。** `table` 设 `relative` 当靠山，`caption` 设 `absolute` 加 `top: -2.25rem`，提到 table 的 `margin-top: 3rem` 腾出来的空白里。这就是第 1 题原样。

8. **年份条 sticky。** `sticky` 加 `top: 0` 滚到顶粘住，这是第 2 题。`z-index: 999` 的原因：table 设了 `relative`，也是已定位元素，两者 z-index 都是默认时按 HTML 顺序画，table 在后面，滚动时会盖住年份条。

**四、布局与视觉技巧**

9. **两处负 margin。** `#years` 的 `margin: 0 -2px` 让深色条左右各伸出 2px，盖住 section 的边框。`.description` 的 `margin-right: -13.5rem` 让说明文字伸到右边三列数字下面，不被挤在窄窄的 th 里。

10. **13.5rem 的来历，顺带一个隐患。** 每个 td 是 `width: 4rem` 加左右 padding 各 0.25rem，共 4.5rem，三列就是 13.5rem，正好对上年份条每个 span 的 `width: 4.5rem`。能这样加，是因为 `box-sizing: border-box` **只写在了 html 上**，而 box-sizing 不会继承，td 仍是默认的 content-box（padding 加在 width 外面）。常见写法会再补一条 `*, *::before, *::after { box-sizing: inherit; }` 让全页继承，这里没写，所以那条 html 规则其实只作用于 html 自己。这是"测试通过 ≠ 写法到位"的一个例子。

11. **渐变硬色标。** `linear-gradient(to bottom, #dfdfe2 1.845rem, white 1.845rem)` 里两个颜色停在同一位置，中间没有过渡距离，变成一刀切的分界：上面 1.845rem 灰，下面白，只给每行的第一行文字垫灰底。

12. **`:nth-of-type` 按类型数。** total 行里第一个是 th，后面三个 td。`td:nth-of-type(3)` 只数 td，选中第三个 td（当年那列）；如果写成 `nth-child(3)`，会把 th 也算进去，选中的是第二个 td。和下午的结论同源：结构伪类数的都是 HTML 结构。

13. **几个小件。** `border-collapse: collapse` 合并相邻单元格的边框；`4px double` 画双线，模仿会计报表合计行的双下划线；`vertical-align: top` 让数字和行标题顶端对齐；`tr.total:hover` 整行悬停变色。
