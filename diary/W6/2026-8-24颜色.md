## 学了什么:
### 色彩理论
原色：红、黄、蓝
间色（两种原色混合）：绿、橙、紫...
复色（原色+邻近色）：黄绿、蓝绿、蓝紫...
色温：暖色、冷色
色彩模型：RGB、HSV、HSL
色轮：![alt text](<images/Color wheel.webp>)
### 命名色
140种命名色：如red、blue、yellow、aqua、fuchsia、black
命名颜色对于快速原型设计、简单设计和提高代码可读性非常有用
### RGB
直接对应于屏幕显示色彩的方式。 显示器和显示屏使用微小的红、绿、蓝像素来产生你所看到的颜色。
RGB 模式是动态设计的理想选择。
值：0-255
```
element {
  color: rgb(red, green, blue);
}
```
rbga(0,0,255,0.5)
a: alpha:透明度0-1.
### HSL
灵活且直观的颜色处理方式
值：色相（0-360）、饱和度（0%-100%）、亮度（0%-100%）、透明度（0-1）
```
element {
  color: hsl(hue saturation lightness / alpha);
}
```
### 十六进制RGB
精确、兼容且易于使用 
超过1600万种颜色
合对一致性要求较高的设计
值：#000000-#ffffff
加透明度#00000000-#ffffffff
简写：#000 #fff #0008 #fffA
```
element {
  color: #RRGGBB;
}
```
### 线性渐变、径向渐变
只要是能使用图片的地方，就可以使用渐变
to right可以写成90deg（角度方向）更精准
```
background: linear-gradient(to right, red, blue);
background: linear-gradient(90deg, red, yellow, blue);
background: radial-gradient(circle, red, blue);
background: radial-gradient(ellipse at top left, red, blue);
background: linear-gradient(to right, red 20%, yellow 40%, blue 80%);
```

### box-shadow 属性
定义：box-shadow 属性在一个元素周围应用一个或多个阴影。
偏移值：你必须指定水平（offset-x）和垂直（offset-y）值。正的 offset-x 会将阴影向右移动，负值则向左移动。正的 offset-y 会将阴影向下移动，负值则向上移动。如果值为 0，则无需包含单位。
模糊半径：此可选的值控制阴影的模糊程度。如果未包含，则默认为 0，这会创建犀利的边缘。数值越大，阴影越柔和。
扩散半径：此可选的值控制阴影的扩展或收缩程度。如果未包含，则默认为 0。
阴影颜色：你可以使用命名颜色、十六进制值、rgb()、rgba()、hsl() 或 hsla() 函数来指定颜色。
inset 关键字：添加 inset 关键字会将阴影放置在元素内部，而不是外部。
应用多个盒子阴影：你可以通过逗号分隔来应用多个阴影。阴影从前到后分层。
语法
```
box-shadow: offset-x offset-y blur-radius spread-radius color;
```
