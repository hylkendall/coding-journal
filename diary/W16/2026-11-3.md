### 条件逻辑和数学方法（理论）

**1. if / else if / else 和三元运算符**
从上往下检查条件，只执行第一个 truthy 的分支，后面的全部跳过；`else` 在上面都不成立时兜底。三元运算符 `条件 ? a : b` 是简单二选一的简写，逻辑复杂时用 `if / else`。这课还给了完整的 falsy 清单：`false`、`0`、`""`、`null`、`undefined`、`NaN`。

**2. 二元逻辑运算符**
三个都从左往右看，结果一定下来就停（短路求值），交出停下的那个值；一路没停就交最后一个。`&&` 找第一个 falsy，`||` 找第一个 truthy，`??` 找第一个不是 `null` / `undefined` 的值。交出的是值本身，不一定是 `true` / `false`。
`??` 和 `||` 的区别在"什么算没填"：`||` 把所有 falsy 都当没填，`??` 只认 `null` 和 `undefined`。所以 `volume = 0` 时，`volume || 50` 是 `50`（把用户的静音覆盖了），`volume ?? 50` 是 `0`。`0`、`""`、`false` 也算有效值时，默认值用 `??`。

**3. Math 对象**
`Math.random()` 返回 0（包含）到 1（不包含）的随机小数。取整三兄弟：`ceil` 向上，`floor` 向下，`round` 取最近（正数 .5 往上进）。`trunc` 只砍小数，正数跟 `floor` 一样，负数不同：`Math.floor(-4.7)` 是 `-5`，`Math.trunc(-4.7)` 是 `-4`。另外 `min` / `max` 取最小 / 最大，`abs` 绝对值，`sqrt` / `cbrt` 平方根 / 立方根，`pow(a, b)` 等于 `a ** b`。
区间随机整数公式 `Math.floor(Math.random() * (max - min + 1)) + min`：`+ 1` 是因为乘数要等于区间里整数的个数，5 到 10 是 6 个。像数楼层，5 楼到 10 楼跨 5 段楼梯，但经过 6 层。
