### 比较和布尔操作符（理论）

**1. 相等和不相等**
`==` 会先做类型强制转换再比，`===` 要求类型和值都相同，不做转换：`5 == "5"` 是 `true`，`5 === "5"` 是 `false`。`!=` 和 `!==` 分别是它们的反面。习惯上一律用 `===` 和 `!==`。

**2. 比较运算符**
`>` `>=` `<` `<=`，结果都是布尔值。`6 >= 6` 是 `true`，`6 > 6` 是 `false`。

### 创建逻辑检查应用（研讨会）

**3. truthy 和 falsy**
falsy 值有 `""`（空字符串）、`0`、`false`、`null`、`undefined` 等，放在条件里当 `false` 用。非空字符串、非零数字、`true` 是 truthy，当 `true` 用。

**4. if / else**
`if (条件) { ... }` 条件为 truthy 才执行；加上 `else { ... }`，条件为 falsy 时执行 else 那块。

### 一元和位操作符（理论）

**5. 一元运算符**（只作用于一个值）
`+` 把值转成数字：`+"42"` 是 `42`，`+"abc"` 是 `NaN`，跟 `"abc" * 2` 是 `NaN` 同一条规则。`-` 转成数字再翻转正负号。`!` 翻转布尔值，`!!` 翻两次：用在布尔值上回到原值，用在别的值上得到它是 truthy 还是 falsy（`!!"abc"` 是 `true`）。`typeof` 返回类型名。`void` 照常执行后面的表达式，但交出的值永远是 `undefined`。

**6. 位运算符**
转成二进制（权重 8 4 2 1），上下对齐一列一列算：`&` 两个都是 1 才是 1，`|` 有一个 1 就是 1，`^` 不一样才是 1。三个捷径：`~x` 是 `-(x + 1)`，`x << n` 是乘 2 的 n 次方，`x >> n` 是除以 2 的 n 次方再向下取整（只记正数）。
