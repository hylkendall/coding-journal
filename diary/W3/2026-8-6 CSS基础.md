## 学了什么:
### CSS是什么
全称为层叠样式表，是现代网页开发中一个关键的组件。它是一种用于为 HTML 应用样式的样式表语言。简单来说，如果 HTML 是网页的结构，CSS 就是让它看起来美观的东西。
一个 CSS 规则由两个主要部分组成：一个 选择器 和一个 声明 块。
### 基本语法：
```
selector {
  property: value;
}
```
元素，比如‘p’直接p开头，无需符号。
在这个选择器列表中，有一个 id 选择器针对 id 值为 title 的超文本标记语言元素。所有 id 选择器必须以井号 # 符号开头。
然后是一个逗号，后面跟着一个 class 选择器，目标是所有 class 值为 subheading 的 HTML 元素。所有类选择器必须以点号（.）开头。
```
#title,
.subheading {
  color: navy;
}
```

### Meta Viewport 
向浏览器提供如何控制页面维度和缩放的指令，特别是在移动电话和平板电脑上。
```
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
避免：元素还允许你控制用户是否可以放大或缩小你的网页。虽然可以通过 user-scalable=no 属性禁用缩放，但通常建议出于无障碍原因避免这样做。

### CSS 可以通过三种主要方式应用到网页中：内联、内部或外部。
内联 CSS 的示例:(避免使用)
```
<p style="color: green;">This is an inline-styled paragraph.</p>
```
内部 CSS 示例：
```
<head>
  <style>
    p {
      color: blue;
    }
  </style>
</head>
<body>
  <p>This paragraph is styled using internal CSS.</p>
</body>
```
外部 CSS 示例：
index.html
```
<head>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <p>This paragraph is styled using external CSS.</p>
</body>
```
styles.css
```
p {
  color: red;
}
```
rel 属性，该属性指定当前文档与链接资源之间的关系
### 宽度和高度
width height
单位：
像素（px）、百分比（%）、视口单位（vw、vh）等。
默认值：
auto
最小控制单位(width height值小于这个不生效)：
min-width
min-height
最大控制单位(与最小同理)：
max-width
max-height
示例：
```
<head>
  <style>
    .box {
      width: 100px;
      height: 100px;
      background-color: skyblue;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
```
CSS 优先考虑 min-width 和 min-height，而不是 width 和 height。如果值超过限制，max-width 和 max-height 会限制维度。

### CSS组合器
在选择器selector处设定渲染影响的范围
| 符号 | 名称 | 关系 | 选中谁 |
|---|---|---|---|
| `空格` | 后代 descendant | 往下，不限代数 | A 里面所有的 B（儿子、孙子、曾孙都算） |
| `>` | 子代 child | 往下，只一代 | A 的直接儿子 B（孙子不算） |
| `+` | 相邻兄弟 next-sibling | 平辈，紧挨着 | 紧跟在 A 后面的那一个 B |
| `~` | 通用兄弟 subsequent-sibling | 平辈，之后全部 | A 后面所有的 B（同一个爹） |

### inline、block 和 inline-block
内联、块、内联块。
内联：渲染行中一段内容，不换行
块：渲染整行整段内容，换行
内联块：可以在渲染一行的一段内容的时候设定宽高，不换行。
示例：
index.html
```
<link href="styles.css" rel="stylesheet">

<div class="container">
  <span class="inline-block-element element1">Inline-Block</span>
  <span class="inline-block-element element2">Inline-Block</span>
</div>
```
styles.css
```
.inline-block-element {
  display: inline-block;
  width: 150px;
  height: 100px;
}

.element1 {
  background-color: lightblue;
}

.element2 {
  background-color: lightgreen;
}
```
### margin 和 padding
-top -right -bottom -left
以border为例，margin在以border为盒子在外面垫空气（距离数值）
padding是把border这个盒子撑大，撑大的程度就是设定值
一个值：上下左右
两个值：上下、左右
三个值：上、左右、下
四个值：上、右、下、左
