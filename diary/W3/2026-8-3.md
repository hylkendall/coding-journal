- 今日主题:无障碍
- 学了什么:
1 WAI-ARIA 是网络无障碍倡议 - 无障碍富互联网应用（Web Accessibility Initiative - Accessible Rich Internet Applications）的缩写。
  它是一种增强动态内容和 UI（用户界面）组件无障碍性的规范。
  这些内容和组件没有原生 HTML 对等内容。
2 ARIA 角色(role属性)有六大类：
  文档结构角色
  小部件角色
  地标角色
  动态区域角色
  窗口角色
  抽象角色
3 aria-label（单独元素） 和 aria-labelledby（关联单个或多个）
  「待补充」
4 aria-hidden
  如果你需要在显示内容的同时对使用屏幕阅读器等辅助技术的用户隐藏内容
  常用于： 
    只有装饰作用的图标和图像。
    重复的内容。

  切勿使用 aria-hidden 隐藏可通过键盘聚焦的元素。 aria-hidden 属性只会从可访问性树中删除元素。 它不会将其从 DOM 中删除。 这样，屏幕阅读器用户仍然可以通过 tab 键找到该元素，但他们的屏幕阅读器将不会阅读该元素，这实际上会导致他们将注意力集中在“空白”上。

  在下列情况下，你无需使用 aria-hidden ：
    HTML 元素已经有一个 hidden 属性。
    元素或其祖先已经用 display: none 隐藏。
    元素或该元素的祖先已经用 visibility: hidden 隐藏。
  在这三种情况下，该元素已经从无障碍树中隐藏，因此不需要使用 aria-hidden 属性。

5 Aria-describedby
   它在元素和内容之间创建了一个程序关联（技术上称为无障碍描述），屏幕阅读器可以利用它在用户与元素交互时告知用户附加信息。

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Accessible Controls</title>
  </head>
  <body>
    <h1>Audio Controls</h1>
    <button type="button">Play</button>
    <div>
      <span id="volume-label">Volume</span>
      <span id="volume-description">Adjust the sound level</span>
      <input type="range" min="0" max="100" value="50" aria-labelledby="volume-label volume-description">
    </div>
    <button type="button">Mute</button>    
  </body>
</html>

7 alt使用要点：
  你应尽量使用简短的 alt 文本。 它应该足够详细，以便理解图像，但也不要太长，以免造成混乱。
  你不应试图描述每一个小细节。 关注图像最重要的方面。
  通常，你不需要以“image of”或“picture of”开头。你可以直接开始描述。
  此外，如果图片周围有类似的文字，alt 可以省略。
  为了保持一致，通常建议在 alt 文本末尾加上句号。
  如果图片是指向另一个页面的链接，alt 文本不应描述图片本身，而应描述用户点击后会发生什么。
