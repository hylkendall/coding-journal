## 今日主题:列表和链接样式

## 学了什么:
### margin或line-height为列表设置间距。
  margin-bottom: 40px; 间距为固定值
  line-height: 2; 间距随font-size变化（值为倍率）
### list-style
1. list-style-type
  设置列表符号外观
2. list-style-position
  默认值：outside
  inside把项目符号或数字放入内容内部。
3. list-style-image
  图像用作列表项的项目符号
4. 可以一起指定
  例子：
```
<ul style="list-style: square inside url('https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg');">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```
### 默认链接样式对网页可用性很重要
虽然可以自定义 link 样式，但应维护默认样式背后的原则。
它们在创建可用且可访问的网页体验中起着关键作用，帮助用户有效地导航和交互内容。
在为你的网站设计链接样式时，始终优先考虑清晰度和用户体验。
### 链接有不同的状态
pseudo-classes伪类
pseudo-class 的语法看起来像这样，其中 A 是选择器，:B 是 pseudo-class：
```
A:B {
  property: value;
}
```
1. :link 链接样式
2. :visited 访问后样式
3. :hover 悬停样式
4. :focus tab选定样式
5. :active 点击时样式
