## 学了什么:
### 背景Image
1. background-image
例：
```
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
```
2. background-size
contain（缩放尽可能大、不拉伸） cover（拉伸到整个范围）
3. background-repeat
默认值repeat
不重复no-repeat
横向重复：repeat-x
纵向重复：repeat-y
4. background-position
top、bottom、left、right 和 center
5. background-attachment
scroll(默认)背景随内容滚动
fixed不滚动
6. 简写
```
<style>
  body {
    background: center top fixed
      url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
  }
</style>
```
### 背景渐变
1. 线性渐变
语法：background: linear-gradient(direction, color-stop1, color-stop2, ...);
direction:方向指定渐变的方向。它可以是角度（例如 45deg）、关键字（例如 to right、to bottom）或边/角。
```
.linear-gradient{
  background: linear-gradient(to right, red, yellow);
  height: 40vh;
}
```
2. 径向渐变
语法：background: radial-gradient(shape size at position, color-stop1, color-stop2, ...)
shape:circle或ellipse
size:closest-side、closest-corner、farthest-side 或 farthest-corner。(边界渐变停止位置)
position： 决定渐变中心的位置，可以使用关键字（例如 center、top left、bottom right）或精确数值（例如 50% 50%、10px 20px）来指定。
```
.radial-gradient{
  background: radial-gradient(circle closest-side at center, red, yellow 50%, green);
  height: 60vh;
}
```
### 背景无障碍
《网页内容无障碍指南》（WCAG）建议，普通文字的对比度最低为 4.5:1，大文字的对比度最低为 3:1。
另一个需要考虑的是避免将文本放置在繁忙或复杂的背景上
在设计背景时，避免仅使用颜色作为传达信息的唯一方式
应该使用符号或文本来传达信息
务必始终提供一种方式让用户静音或暂停音频
