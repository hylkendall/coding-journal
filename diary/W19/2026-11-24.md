**一、条件判断的顺写法（冷启动）**
1. 先用正面的话写"合法是什么样"：`return unit === "kg" || unit === "lb";`。比较本身就会得到 `true`/`false`，不用再套 `if`。
2. 要判断不合法，就在外面加 `!`：`!["kg", "lb"].includes(unit)`，读作"不在清单里"。合法值变多时只要往数组里加。
3. `!(A || B)` 等于 `!A && !B`。昨天写的 `unit !== "kg" && unit !== "lb"` 没错，只是读着绕。
4. `includes` 是精确匹配，区分大小写。它收到的只是一个值，不管这个值是不是从对象里取出来的。

**二、传参和赋值（冷启动）**
1. 赋值本身也有结果，就是等号右边的值。`return result.qty = "Invalid"` 交出去的是 `"Invalid"`，不是 `result`。
2. 两个函数里同名的参数是两个不同的变量。括号里算出来是什么，传过去的就是什么：`check(item.qty)` 等于 `check(0)`。
3. `0.qty` 是 `undefined`，`undefined <= 0` 是 `false`。所以传错参数不会报错，只会悄悄得到 `{}`。
4. 调试办法：不确定函数收到了什么，就在函数第一行 `console.log` 一下参数。

**三、JSON**
1. JSON 是一种文本格式，常用来在服务器和网页之间交换数据，跟编程语言无关。
2. 能存对象、数组、字符串、数字、布尔值和 `null`。键必须用双引号。
3. 读值用点号或方括号，键里有空格时只能用方括号：`data["list of courses"]`。
4. `JSON.stringify(obj)`：对象 → JSON 字符串。转完是字符串，所以 `.name` 读不到，得到的是 `undefined`。
5. `JSON.parse(str)`：JSON 字符串 → 对象。取值写 `JSON.parse(s).age`。
6. `stringify` 有两个可选参数，平时很少用：第 2 个参数给数组，就只保留这些属性；`JSON.stringify(obj, null, 2)` 表示每层缩进 2 个空格。
7. 钩子：`import data from "./x.json" with { type: "json" }` 和 `localStorage` 后面会正式学。

**四、可选链 `?.`**
1. `user.address.street`：`address` 不存在时会报 `TypeError`。
2. `user.address?.street`：`?.` 前面的值是 `null` 或 `undefined`，就直接返回 `undefined`，不再往下读，也不报错。
3. 它只负责不报错，不会给默认值。想要默认值就接 `??`：`user.address?.street ?? "N/A"`。

**五、对象解构**
1. `const { time, title } = recipe;` 按属性名取值，跟顺序无关。数组解构是按位置取。
2. `:` 是改名：`{ title: dish }` 把 `title` 读进变量 `dish`，`title` 本身不会变成变量。
3. `=` 是默认值：`{ level = "easy" }`，属性不存在时才用。值是 `null` 不算不存在，不会用默认值（我在 Node 里试过）。
4. 嵌套：`const { ingredients: { flour } } = recipe;` 等于 `recipe.ingredients.flour`。只有 `flour` 成了变量，`ingredients` 不是。

**六、简写 `{ name, age }`**
1. 写在 `=` 右边是把变量装进对象，等于 `{ name: name, age: age }`。常见于 `return { name, age }`。
2. 写在 `=` 左边是解构，把属性拆出来放进变量。同样的花括号，方向相反。
3. 补充：意思是 `{ title, time }` 这串字长得一模一样，但放在 `=` 的哪一边，做的事正好相反。

**放在右边：打包**，把几个变量装进一个新对象。

```javascript
const title = "Soup";
const time = 15;

const r = { title, time };
console.log(r);   // { title: 'Soup', time: 15 }
```

**放在左边：拆包**，把对象里的属性取出来，放进同名的变量。

```javascript
const recipe = { title: "Cake", time: 40 };

const { title, time } = recipe;
console.log(title, time);   // Cake 40
```

就像快递箱，一个是把东西装进箱子，一个是从箱子里把东西拿出来，用的是同一个箱子。

判断方法只看一眼：花括号在 `=` 右边，就是在造一个对象；花括号在 `=` 左边，而且前面有 `const`，就是在声明变量。
