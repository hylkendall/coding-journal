**一、变量名 vs 字符串**
1. 不加引号是变量名，JS 去找这个变量里装的东西。`getSpecies(tiger)` 传进去的是那个对象。
2. 加了引号就是文字本身。`"tiger".species` 是 `undefined`。
3. `getProperty(tiger, "species")`：对象不加引号，属性名加引号。

**二、给对象加、改、删属性（研讨会）**
1. `obj.prop = value`：属性不存在就新加，存在就更新，改的是原对象。
2. `delete obj.prop` 删掉属性。`obj.hasOwnProperty("prop")` 查属性在不在，更推荐 `Object.hasOwn`。
3. 方括号配参数：`animal[propertyName]`，属性名由调用时传进来。
4. `animal.habitat = habitat`：点号后面是属性名，等号右边是参数变量。同名的写法很常见。

**三、复制对象 `{ ...obj }`**
1. 跟 `[...arr]` 一样会新造一个对象，改 copy 自己的属性不影响原对象。
2. 它也是浅拷贝，里面装的对象两边共用。
3. 钩子：深拷贝用 `structuredClone(obj)`，不在 fCC 大纲里。

**四、判断属性在不在**
1. 对象里没有"有名字没值"这种状态，`{ id: }` 是 SyntaxError。
2. `Object.hasOwn(obj, "名字")` 只看属性在不在。值是 `0`、`null`、`undefined` 都算在。
3. `!obj.prop` 看的是值，`0` 是 falsy，会被当成不在。
4. 只有字符串和数组有 `.length`。数字的 `.length` 是 `undefined`，`undefined.length` 会报 TypeError。
5. 属性名区分大小写，拼错了不报错，只会悄悄得到 `undefined`。在 VS Code 里双击一个词，同名的会全部高亮。

**五、数字检查**
1. `Number.isInteger(x)`：小数和非数字（字符串、`null`、`NaN`）都返回 `false`，负整数返回 `true`，所以要正整数还得加 `> 0`。
2. `typeof NaN` 是 `"number"`，NaN 跟任何数比大小都是 `false`。要用 `Number.isNaN(x)` 专门查。

**六、逻辑运算符**
1. `||` 会短路：左边是 true 就不算右边了。所以要先查类型再调方法：`typeof d !== "string" || d.trim() === ""`。顺序反过来，`405` 会报 `TypeError: d.trim is not a function`。
2. `||`、`&&` 两边都要写完整的比较。`unit !== "kg" || "lb"` 会被读成 `(unit !== "kg") || "lb"`，`"lb"` 是 truthy，条件永远成立。
3. "既不是 A 也不是 B"写成 `x !== A && x !== B`。换成 `||` 的话，任何值至少跟其中一个不相等，永远是 true。

**七、校验函数的套路（lab）**
1. 开头先造一个空对象 `result`，只往它上面写，不碰输入，这样就不会改到原对象。
2. 每个属性：`if`（不在）→ Missing；`else if`（不合法）→ Invalid；合法就什么都不做。
3. 分支里不写 `return`，全部查完后在最后 `return result` 一次。`return a.b = "x"` 会让函数立刻结束，而且交出去的是 `"x"`，不是对象。
4. 全部合法时，返回的自然就是 `{}`。

**八、函数之间传什么、接什么（processManifest）**
1. 调度函数自己不做判断，只调用别的函数、使用它们的返回值。先用 `const` 存起来再用。
2. 判断空对象：`obj === {}` 永远是 `false`，因为又造了一个新对象。要写 `Object.keys(obj).length === 0`。这个方法还没教，fCC 参考答案就用的它。
3. 传整个对象还是传一个属性，看函数要什么。`normalizeUnits(manifest)` 不能写成 `normalizeUnits(manifest.weight)`，`{ ...400 }` 得到的是 `{}`。
4. 对象放进模板字符串会显示成 `[object Object]`，要取属性就写 `normalizeUnits(manifest).weight`。
5. 题目要打印就用 `console.log`。`return` 只是把值交出去，不会显示任何东西。

**九、写函数前的三行注释**：① 输入是什么 ② 有哪几种情况 ③ 每种情况打印什么、返回什么。
