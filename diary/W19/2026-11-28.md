**第 4 题**（已知有错）

```javascript
const saved = '{"name":"Ann","cart":["pen"]}';
const user = JSON.stringify(saved);
user.cart.push("book");
console.log(user.cart);
```

我答的：第二行，写反了，应该"解构"成对象：`const user = JSON.parse(saved);`
结果：改法对，改完打印 `["pen", "book"]`。
补两点：

1. **报错是在第三行，错在第二行。** `stringify` 不报错，它把字符串又包了一层，得到的还是字符串。字符串上没有 `cart`，`user.cart` 是 `undefined`，对它调 `.push` 才报错：`TypeError: undefined is not an object (evaluating 'user.cart.push')`。红字指的是程序停下的那一行，要顺着往上找这个 `undefined` 是从哪来的。
2. **用词：解析 ≠ 解构。** `JSON.parse` 是解析，把 JSON 文字变成对象。解构是 `const { id } = order` 这种写法，把属性拆出来放进变量。

### 三、小项目：图书借阅管理

**`addBook`**

问题：对在对象里添加数据没什么印象了。
答：问答第 1 题的 `pet.color = "white"` 就是在加属性。加和改是同一个写法，属性不在就是加。

我写的：

```javascript
library = id;
library[id] = title, author, available = true, borrowers = [];
return `Added ${library[id][title]}`;
```

结果：在 Node 里跑，第一行就报 `TypeError: Assignment to constant variable.`。删掉第一行再跑，打印 `Added undefined`，`library.b3` 只是一个字符串 `"Emma"`。

错在哪：

1. `library = id` 是把整个 `library` 换成字符串 `"b3"`，而 `library` 又是 `const`，所以报错。要找到 b3 的位置，`library[id]` 已经够了。
2. 逗号不会把几样东西打包在一起，`=` 只把 `title` 存了进去。`available = true` 和 `borrowers = []` 变成了跟这本书无关的两个变量。
3. `library[id][title]` 里的 `title` 是参数，装的是 `"Emma"`，等于去找一个叫 `"Emma"` 的属性，所以是 `undefined`。

正确写法（我第二次写的）：

```javascript
library[id] = { title, author, available: true, borrowers: [] };
return `Added ${title}`;
```

问题：简写和普通写法混在一对花括号里，感觉不对劲？
答：没问题，可以混着用。`title`、`author` 等于 `title: title`、`author: author`；`available`、`borrowers` 没有同名变量，就直接写值。

**`borrowBook`**

问题：报错看不懂，哪里写错了？

**最终提交**

结果：15 行对上 14 行。第 6 行预期 `Emma: no one yet`，实际打印 `Emma: `。
我写的：`if (library[id].borrowers === "")`
错在哪：`borrowers` 是数组，`""` 是字符串，`===` 两边类型不一样就直接是 `false`。所以条件永远不成立，每次都走 `else`，空数组 `join` 出来是空字符串。

问题：一定要先把数组转成字符串再判断吗？不能直接对数组做判断？
答：可以直接判断，用长度：

```javascript
if (library[id].borrowers.length === 0) {
```

`borrowers === []` 不行，永远是 `false`。`[]` 每写一次就造一个新数组，`===` 比的是"是不是同一个数组"，跟第 5 题是同一个道理。

一次写对的：`getBookInfo`、`returnBook`。
