## 今日主题:CSS 定位
## 学了什么:
float 是老布局遗产,position 是另一套坐标系。分开记就不乱了。

**position 五个值**

| 值 | 参照谁 | 原来的位子还占着吗 | top/left 生效 | z-index 可用 |
|---|---|---|---|---|
| static(默认) | 不参照,排队 | 占着 | ❌ 无效 | ❌ |
| relative | **自己原来的位置** | **占着**(后面的不补上来) | ✅ | ✅ |
| absolute | 最近的**已定位祖先**(position 非 static 的);找不到就用初始包含块 | **不占了**(后面的补上来) | ✅ | ✅ |
| fixed | **视口** | 不占了 | ✅ | ✅ |
| sticky | 最近的**滚动容器**,阈值内像 relative、过了阈值被粘住 | 占着 | ✅(必须写,否则不粘) | ✅ |

一句话记法:**relative 是"人还在队里,只是身子歪一下";absolute 是"离队飘走,后面补位";fixed 是"贴在屏幕玻璃上";sticky 是"正常走到门口被卡住"。**

**float**

| 要点 | 说明 |
|---|---|
| `float: left / right` | 元素靠边浮起,**半脱离**文档流 |
| 半脱离什么意思 | 块级盒子当它不存在、直接穿过去;但**文字/行内内容会绕着它走** ← 这是 float 和 absolute 最大的区别 |
| 高度塌陷 | 子元素全浮动时,父容器算不出高度,塌成 0 |
| `clear: left/right/both` | 让本元素不与前面的浮动并排,下移到浮动下方 |
| 现代收尾法 | 父元素加 `display: flow-root`(或老式 clearfix) |
| 今天还用它吗 | 基本只剩"文字环绕图片"这一个正当用途,布局已被 flex/grid 接管 |

整张表里最值钱的一行就是那个对比:**float 是半脱离(文字避开它),absolute 是全脱离(谁都看不见它)**。这一条记住,后面很多怪现象都能自己解释。

## 卡壳的点:
疑问一:absolute 不写坐标会跑哪?
你猜浏览器左上角。实验推翻了——它原地不动。解法:top/left 默认是 auto,而 absolute 下的 auto 意思是"回到静态位置"。出列 ≠ 走人。

疑问二:为什么非得给父元素加 relative?
因为 absolute 往上爬找参照物,只认 position 非 static 的祖先;static 是默认值,不够资格,会被爬过去。relative 单用不挪动自己,纯粹是挂牌当原点——所以"父 relative + 子 absolute"成了固定搭配。

疑问三:relative 和 absolute 都"不动",是同一回事吗?
你答了"都是 auto",对一半。同一个 auto,两种解释:relative 下是 0(没离队,不偏移),absolute 下是静态位置(离了队,被放回影子位)。证据是第三个盒子——absolute 时补位,relative 时不补。视觉一样,流里后果不同。

疑问四:同样写 top:0 left:0,为什么 absolute 待在父元素里,fixed 直接贴屏幕?
这个是你自己主动发现的,含金量最高。因为两者问的不是同一个人:absolute 问"最近的已定位祖先在哪",fixed 问"屏幕在哪"。父元素的 relative 对 fixed 完全是空气。

卡 1
正面:position: absolute 但不写任何 top/left/right/bottom,元素会出现在哪?
背面:原地不动(静态位置)。auto 对 absolute = "回到我本来该在的位置"。不占位了,但没走。
标签:CSS::定位

卡 2
正面:relative 和 absolute 都不写偏移时都"不动",原因相同吗?
背面:不同。relative 下 auto=0(没离流);absolute 下 auto=静态位置(已离流)。区别看后一个元素补不补位。
标签:CSS::定位

卡 3
正面:父元素写了 position: relative,子元素 fixed 加 top:0; left:0 会贴到哪?
背面:屏幕左上角。fixed 只认视口,无视已定位祖先——父元素的 relative 对它不起作用(对 absolute 才起)。
标签:CSS::定位

卡 4
正面:一个元素 z-index: 5 但 position: static,另一个 z-index: 10,谁在上面?
背面:10 那个。static 上的 z-index 被完全忽略,不是"输给了 10"。z-index 是定位元素的特权。
标签:CSS::定位
