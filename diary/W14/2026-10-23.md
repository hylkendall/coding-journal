**卡 1**

正面
```
What is an audio description, and who is it for? For an audio-only podcast, what should you provide for users who are deaf or hard of hearing?
- - - - - - - - - -
什么是音频描述（audio description）？给谁用？纯音频的播客，要给听障用户（deaf / hard of hearing）提供什么？
```

背面
```
Audio description: a spoken narration that describes the important visual content of a video, for users who are blind or visually impaired.
"Audio" is its form (you hear it), not what it describes (it describes the picture).
Audio-only podcast: provide a transcript, so users who are deaf or hard of hearing can read what is said.
- - - - - - - - - -
音频描述：用旁白讲出视频里重要的画面内容，给视障用户（blind / visually impaired）。
audio 是它的形式（用耳朵听），不是它描述的对象（它描述的是画面）。
纯音频播客：提供文字稿（transcript），让听障用户读到说了什么。
```

标签
```
html::accessibility
```

**卡 2**

正面
```
What is WAI-ARIA? Which attributes belong to it?
- - - - - - - - - -
WAI-ARIA 是什么？哪些属性属于它？
```

背面
```
A set of attributes added to HTML elements to improve accessibility: the role attribute and the aria-* attributes (e.g. aria-label, aria-describedby, aria-hidden).
It is not CSS, and it is not a program or a tool.
alt, tabindex and lang also help accessibility, but they are ordinary HTML attributes, not part of WAI-ARIA.
- - - - - - - - - -
一组加在 HTML 元素上、用来提升无障碍的属性：role 属性和 aria-* 这一家子（比如 aria-label、aria-describedby、aria-hidden）。
它不是 CSS，也不是程序或工具。
alt、tabindex、lang 也对无障碍有用，但它们是普通 HTML 属性，不属于 WAI-ARIA。
```

标签
```
html::accessibility
```

**卡 3**

正面
```
How do you give an HTML element an ARIA role, such as the tab role? Is aria-role a valid attribute?
- - - - - - - - - -
怎么给一个 HTML 元素加 ARIA 角色，比如 tab 角色？aria-role 是合法的属性吗？
```

背面
```
Use the role attribute: role="tab".
aria-role does not exist. role is the only ARIA attribute without the aria- prefix; all the others start with aria- (aria-label, aria-hidden, ...).
- - - - - - - - - -
用 role 属性：role="tab"。
没有 aria-role 这个属性。role 是 ARIA 里唯一不带 aria- 前缀的属性，其余的都以 aria- 开头（aria-label、aria-hidden……）。
```

标签
```
html::accessibility
```
