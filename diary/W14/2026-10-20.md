**卡 1**

正面
```
In HTML, cite is both an element and an attribute. What does each one contain, and is it shown on the page?
- - - - - - - - - -
HTML 里的 cite 既是元素也是属性。两者各自放什么内容？会不会显示在页面上？
```

背面
```
The <cite> element wraps the title of a referenced work (a book, article, film or song), not the author's name. It works like the Chinese title marks 《》, and it is shown on the page (italic by default).
The cite attribute goes on a quotation element such as <blockquote> or <q> and holds the URL of the quote's source. It is not shown on the page.
- - - - - - - - - -
<cite> 元素包被引用作品的标题（书名、文章名、电影名、歌名），不包作者名，相当于中文的书名号《》，会显示在页面上（默认斜体）。
cite 属性写在 <blockquote>、<q> 这类引用元素上，放引文出处的网址，页面上不显示。
```

标签
```
html::semantics
```

**卡 2**

正面
```
What does HTML do by default with consecutive spaces and line breaks in the source code? Which element keeps them exactly as written? Does <code> on its own keep them?
- - - - - - - - - -
HTML 默认怎么处理源码里连续的空格和换行？哪个元素能原样保留它们？单独用 <code> 能保留吗？
```

背面
```
By default they are collapsed into a single space. <pre> keeps spaces and line breaks exactly as written (its default style includes white-space: pre). <code> on its own does not: it only marks text as code and uses a monospace font by default, so whitespace is still collapsed.
- - - - - - - - - -
默认会合并成一个空格。<pre> 原样保留空格和换行（它的默认样式里有 white-space: pre）。单独用 <code> 不行：它只把文字标成代码、默认用等宽字体，空白照样会被合并。
```

标签
```
html::semantics
```

**卡 3**

正面
```
<strong> and <b> both look bold by default; <em> and <i> both look italic. What does each of the four elements mean?
- - - - - - - - - -
<strong> 和 <b> 默认都显示成粗体，<em> 和 <i> 默认都显示成斜体。这四个元素各自表示什么？
```

背面
```
<strong>: the content is important, serious or urgent (e.g. a warning).
<b>: draws attention without adding importance (e.g. product names in a review).
<em>: stress emphasis, the word you would stress when speaking.
<i>: text in an alternative voice, such as a foreign word, a technical term or a thought.
Choose by meaning, not by looks. If you only want the look, use CSS.
- - - - - - - - - -
<strong>：内容重要、严肃或紧急（如警告）。
<b>：引起注意，但不代表更重要（如评测里的产品名）。
<em>：语气上的强调，说话时要重读的词。
<i>：和周围不一样的文字，如外语词、专业术语、内心想法。
按含义选，不按外观选。只想要外观，就用 CSS。
```

标签
```
html::semantics
```

**卡 5**

正面
```
What are presentational HTML elements such as <font> and <big>? What should you use instead? Are <i> and <b> deprecated too?
- - - - - - - - - -
<font>、<big> 这类表现型元素是什么？应该改用什么？<i> 和 <b> 也被废弃了吗？
```

背面
```
Elements that only control how content looks and carry no meaning. They are deprecated: not recommended and may be removed, although browsers still display them so that old pages keep working. Instead, use CSS, on a meaningful element, or on a <span> when no meaningful element fits.
<i> and <b> are not deprecated: HTML5 gave them meanings (<i>: text in an alternative voice; <b>: draws attention without adding importance).
- - - - - - - - - -
只管外观、不带含义的元素。它们已被废弃（deprecated）：不推荐使用，以后可能被移除，只是浏览器为了让老网页还能用，目前还会显示。应该改用 CSS，写在有含义的元素上；没有合适的元素时，写在 <span> 上。
<i> 和 <b> 没被废弃：HTML5 给了它们含义（<i>：和周围不一样的文字；<b>：引起注意，但不代表更重要）。
```

标签
```
html::semantics
```

**卡 6**

正面
```
In the datetime attribute of <time>, what is the ISO 8601 format for a date plus a time? Write 8:30 p.m. on December 25, 2026 in this format.
- - - - - - - - - -
<time> 的 datetime 属性里，「日期加时间」的 ISO 8601 格式是什么？用这个格式写出 2026 年 12 月 25 日晚上 8 点半。
```

背面
```
YYYY-MM-DDThh:mm:ss: a capital T separates the date from the time, the time uses the 24-hour clock, and the seconds can be left out. → 2026-12-25T20:30
The datetime value is for machines and is not shown on the page; users see the text inside <time>.
- - - - - - - - - -
YYYY-MM-DDThh:mm:ss：大写 T 隔开日期和时间，时间用 24 小时制，秒可以省略。→ 2026-12-25T20:30
datetime 的值是给机器读的，页面上不显示；用户看到的是 <time> 里面的文字。
```

标签
```
html::semantics
```

**卡 7**

正面
```
Inside a <form>, what happens when you click <button type="reset">? Is the form submitted? Are the fields always left empty?
- - - - - - - - - -
<form> 里点 <button type="reset"> 会发生什么？表单会提交吗？输入框一定会被清空吗？
```

背面
```
Every control in the form goes back to its initial value, and the form is not submitted. The fields are not always emptied: an input written with value="abc" goes back to abc. For a button with no default action at all, use type="button".
- - - - - - - - - -
表单里的每个控件都恢复成初始值，表单不会提交。不一定清空：写了 value="abc" 的输入框会回到 abc。想要完全没有默认行为的按钮，用 type="button"。
```

标签
```
html::forms
```
