下面是网格的梳理。

**先分清谁写在哪**

| 属性 | 写在 | 管什么 |
|---|---|---|
| `grid-template-columns` / `-rows` | 容器 | 画显式轨道，写几个值就是几条 |
| `grid-template-areas` | 容器 | 画区域地图 |
| `gap` / `row-gap` / `column-gap` | 容器 | 轨道之间的缝，网格外边缘不加 |
| `grid-auto-columns` / `-rows` | 容器 | 补出来的隐式轨道多大 |
| `grid-auto-flow` | 容器 | 没认领位置的子项按什么顺序入座 |
| `grid-column` / `grid-row` | 子项 | 我从哪条线到哪条线 |
| `grid-area` | 子项 | 我认领地图上哪一块，名字不带引号 |

看名字就能分辨：带 `template` 或 `auto` 的，全写在容器上；单数的 `grid-column`、`grid-row`、`grid-area` 写在子项上。复数的 columns、rows、areas 是容器在画格子，单数是子项在认领位置。`gap` 系列不带 `grid-` 前缀，是例外，也写在容器上。

**最容易踩的坑**

- `grid-template-rows: 100px` 的意思是"只有一行"，不是"每行 100px"。想让每行都 100px，用 `grid-auto-rows`。
- 容器只负责画格子，不负责分配。子项没写位置，就按 `grid-auto-flow` 自动入座。
- 自动入座时，横着填看列数，竖着填看行数。
- 区域必须是矩形。只要有一块不是，整句 `grid-template-areas` 就失效，所有子项会挤成一堆。
- 容器没设高度时，几个 `1fr` 行会一样高，都跟着需要最高的那一行走。

**常用的值（写在属性后面）**

- `fr`：分剩余空间，优先级最低，最后才分。
- `repeat(3, 1fr)` 就是 `1fr 1fr 1fr`。
- `minmax(最小, 最大)`：单独写 `1fr` 等于 `minmax(auto, 1fr)`，会被长内容撑开；想严格均分，写 `minmax(0, 1fr)`。
- `min-content`：内容能缩到的最窄宽度，对文字来说大约是最长那个单词。
- 线号：从 1 开始，n 列有 n+1 条线。`-1` 是最后一条线，所以 `1 / -1` 是横跨全部显式列。
- `span 2`：跨两格，`1 / 3` 和 `1 / span 2` 效果相同。
- `'.'`：区域地图里的空格子。
