## 产出:

**这页的思路：由外到内，先骨架后皮肤**

1. **先画框，不写代码。** 看着设计图把页面切成大块，大块再切小块。每个框问两个问题：它是什么（标题区？正文？附属内容？），这决定用哪个语义标签；它里面的东西怎么排（一维还是二维），这决定用 flex、grid，还是普通文档流。
2. **照着框写完整个 HTML。** 内容全部放进去，一行 CSS 都不写。页面丑没关系，结构对就行。
3. **全局打底。** reset、根字号、body 的字体颜色背景、标题字体、链接样式。这几条每个项目都差不多，写熟了就是固定开头。
4. **搭最外层的框。** 这页就是 `main` 的三列网格：两边留白，中间版心，然后把每个 section 放进第 2 列。
5. **一块一块搭内部。** 每个大块自己再当容器。一次只做一块，做完在浏览器里看一眼，再做下一块。
6. **最后做装饰和响应式。** 颜色、字号、首字下沉、引号都放在最后。响应式是把窗口从宽往窄拖，哪个宽度开始挤坏了，就在那个宽度加一条媒体查询去修。断点由内容决定，不用去背设备尺寸。

整个过程一直用你那个判断法："容器怎么排"还是"我被怎么排"。这页的网格嵌了三层，每一层都是父元素写 template，子元素写 `grid-column`，分清这一点就不会乱。

**怎么练出这个思路：** 第 1 步最关键，也最容易被跳过。接下来的报纸版面 Lab 就是练习机会：动手前先在纸上或截图上把框画出来，每个框旁边标上"grid 几列 / flex / 普通流"，画完再写 HTML。

也可以倒着练一次：打开这页，在 Safari 检查器里把三层网格的叠加层都打开，对照 HTML 里的结构图，看每层网格各管哪一块。

注释里顺手标了几处这份代码本身的问题，比如社交图标链接没有文字、首屏大图用了 lazy、`.hero` 的 `position: relative` 没起作用。练习项目里这样可以接受，真实项目才需要改，不用回去改。

## 卡壳的点:

**卡 1**
正面：网格容器有 3 列，里面有 3 个子项。① 子项都不写 `grid-column`；② 子项都写 `grid-column: 2 / 3`。两种情况分别怎么摆？
背面：① 按 HTML 顺序，各自填进下一个空格子，三个并排，各占一列。② 三个都进第 2 列，上下叠成 3 行，第 1、3 列空着。容器只画格子，谁进哪格由子项决定，子项不指定位置就按顺序自动填。
标签：`css::grid`

**卡 2**
正面：`.heading` 是 `main` 的子项（`main` 是网格容器），它自己也写了 `display: grid`。它身上的 `grid-column: 2 / 3` 和 `grid-template-columns: repeat(2, 1fr)` 分别作用在哪个网格上？
背面：`grid-column` 描述"我被怎么排"，用的是父元素 `main` 的网格线，把 `.heading` 放进 `main` 的第 2 列。`grid-template-columns` 描述"容器怎么排"，给 `.heading` 自己画两列，用来排它的子元素。
标签：`css::grid`

**卡 3**
正面：`grid-template-columns: minmax(2rem, 1fr) minmax(min-content, 94rem) minmax(2rem, 1fr);` 浏览器按什么顺序给这三列分宽度？
背面：① 先给每列它的最小值；② 中间列往上长，最多长到 94rem；③ 剩下的空间按 `fr` 平分给两边。效果：宽屏时正文定宽居中；窄屏时两边先缩到 2rem 不动，之后只有中间列在缩。
标签：`css::grid`

**卡 4**
正面：CSS 关键字 `min-content` 表示什么宽度？对一段文字来说，大约是多宽？
背面：内容能缩到的最小宽度。对文字来说，大约是最长那个单词的宽度，再窄的话，最长的单词就放不下了。
标签：`css::grid`

**卡 5**
正面：引入 FontAwesome 样式表后，`<i class="fab fa-facebook-f"></i>` 里的 `fab` 和 `fa-facebook-f` 各负责什么？
背面：`fab` 把 `font-family` 设成 FontAwesome 的品牌图标字体。`fa-facebook-f` 用 `::before` 的 `content` 塞进一个字符，这个字符在图标字体里画的是 Facebook 图标。两个类缺一个，都显示不出正确的图标。
标签：`css::pseudo-elements css::typography`

**卡 6**
正面：HTML 的 `<aside>` 用来装什么内容？怎么判断一块内容该不该用它？
背面：装跟主内容相关、但不属于主线的附属内容，比如侧边栏、旁注、相关链接。判断法：把这块拿掉，主内容还读得通吗？读得通，就适合用 `<aside>`。
标签：`html::semantics`

**卡 7**
正面：`grid-column: 1 / -1;` 是什么意思？
背面：从第 1 条网格线到最后一条网格线（-1 是倒数第 1 条），也就是跨满所有显式列，不管一共有几列。
标签：`css::grid`

**卡 8**
正面：为什么很多样式表会写 `html { font-size: 62.5%; }`？写了以后，1rem 等于多少？
背面：浏览器默认字号是 16px，16px × 62.5% = 10px，所以默认设置下 1rem = 10px，换算方便（1.8rem 就是 18px）。用百分比而不直接写 10px，是为了在用户调大浏览器默认字号时，页面还能跟着放大。
标签：`css::units`

**卡 9**
正面：`object-fit: cover` 在什么情况下起作用？效果是什么？
背面：在图片框的宽高比和图片本身的宽高比不一致时起作用。图片保持原比例铺满整个框，多出来的部分被裁掉，图片不变形。默认值 `fill` 则会把图片拉变形去填满。
标签：`css`

**卡 10**
正面：`grid-auto-flow: column` 和默认值 `row` 有什么区别？
背面：`row`（默认）按行填，一行填满换下一行，不够就往下加新行。`column` 按列填，一列填满换下一列，不够就往右加新列。新加出来的隐式列，宽度用 `grid-auto-columns` 设置。
标签：`css::grid`

**卡 11**
正面：`column-width: 25rem;` 属于什么布局？分几栏由谁决定？
背面：CSS 多列布局（像报纸分栏），跟网格是两套东西。25rem 是理想栏宽，分几栏由浏览器按可用宽度自动决定，实际栏宽会调整以填满整行。它对网格容器不起作用。
标签：`css`

**卡 12**
正面：窗口宽 400px。样式表里先写了 `@media (max-width: 550px)`，后写了 `@media (max-width: 420px)`，两段里都有 `.hero-title { font-size: ... }`。哪个生效？为什么？
背面：420px 那段生效。两个媒体查询此时同时生效，而媒体查询本身不增加优先级。两条规则选择器相同、优先级相同，所以写在后面的赢。
标签：`css::responsive`

**卡 13**
正面：用什么写法做出"首字下沉"（段落第一个字母放大，后面的文字绕着它排）？
背面：用 `::first-letter` 选中第一个字母并放大字号，再加 `float: left`，让它浮到左边，后面的文字就会绕着它排。
标签：`css::pseudo-elements`
