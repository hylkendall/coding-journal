#### 基础 CSS

- [ ] **相邻兄弟组合器 `+`** 〔忘了〕\
  `A + B` 选中紧跟在 A 后面的**那一个** B 兄弟。

  ```css
  h2 + p { ... }
  ```
- [ ] **后续兄弟组合器 `~`** 〔忘了〕\
  `A ~ B` 选中 A 后面的**所有** B 兄弟。

  ```css
  h2 ~ p { ... }
  ```
- [ ] **行内元素 · inline** 〔模糊〕\
  只占内容需要的宽度，不另起一行，和文字排在同一行。常见的有 `span`、`a`、`img`。

  > 注：对 `span`、`a` 这类行内元素设 width、height 不生效；`img` 例外，可以设宽高。
- [ ] **块级元素 · block** 〔模糊〕\
  默认占满父容器的可用宽度，独占一行。常见的有 `div`、`p`、`section`。
- [ ] **行内块 · inline-block** 〔模糊〕\
  用 `display: inline-block` 设置。像行内元素一样排在一行，又能像块级元素一样设 width 和 height。
- [ ] **`!important`** 〔模糊〕\
  让这条声明的优先级最高，无视其他选择器的特异性。会让 CSS 难维护、难调试，慎用。

  ```css
  color: red !important;
  ```
- [ ] **层叠算法 · Cascade** 〔模糊〕\
  多条规则同时作用于同一个元素时，浏览器按一套固定规则（`!important`、特异性、源码顺序等）决定最终用哪条。

  > 注：判断顺序：先比特异性，分出高低就结束；打平了才看谁写在后面。
- [ ] **继承 · Inheritance** 〔模糊〕\
  父元素的一部分样式会传给子元素（比如 `color`、`font-family`），不用每个元素都写一遍。

  > 注：不是所有属性都继承，比如 `margin`、`border`、`transition` 就不继承。

#### 伪类和伪元素

- [ ] **用户操作伪类** 〔忘了〕\
  根据用户的交互来改变元素外观的一类伪类，提升使用体验。
- [ ] **`:focus-within`** 〔忘了〕\
  元素**自己或它的任意后代**获得焦点时，选中这个元素。

  ```css
  form:focus-within { outline: 2px solid; } /* 表单里任何输入框聚焦，整个表单高亮 */
  ```
- [ ] **输入伪类** 〔忘了〕\
  根据表单元素在用户交互前后的状态来选中它们。
- [ ] **`:enabled`** 〔忘了〕\
  当前可用（没被禁用）的表单元素。
- [ ] **`:disabled`** 〔忘了〕\
  被禁用的表单元素（带 `disabled` 属性）。
- [ ] **`:valid`** 〔忘了〕\
  满足验证规则的输入框。
- [ ] **`:invalid`** 〔忘了〕\
  不满足验证规则的输入框。
- [ ] **`:in-range` / `:out-of-range`** 〔忘了〕\
  值在 / 不在 `min`–`max` 范围内的输入框，比如 `type="number"`。
- [ ] **`:required`** 〔模糊〕\
  带 `required` 属性、必须填写才能提交的表单元素。
- [ ] **`:optional`** 〔忘了〕\
  没有 `required` 属性、可以留空的表单元素。

  > 注：fCC 中文版把这一条的名字误译成了 `:not()`，以英文为准。
- [ ] **位置伪类** 〔模糊〕\
  用来给链接，以及当前文档里被定位到的元素加样式。
- [ ] **`:link`** 〔忘了〕\
  还没访问过的链接。
- [ ] **`:any-link`** 〔忘了〕\
  `:link` 和 `:visited` 的合集：任何带 `href` 的链接，不管访问过没有。
- [ ] **`:target`** 〔忘了〕\
  URL 里 `#片段` 指向的那个元素。

  ```css
  /* 访问 page.html#about 时，id="about" 的元素匹配 */
  :target { background: yellow; }
  ```
- [ ] **树结构伪类** 〔模糊〕\
  根据元素在文档树里的**位置**来选中它。
- [ ] **`:empty`** 〔忘了〕\
  没有任何子节点的元素。

  > 注：fCC 原文说「只有空白的也算空」，但目前浏览器里空格和换行都算内容，有空白就不匹配。
- [ ] **`:only-child`** 〔模糊〕\
  父元素里唯一的那个子元素。
- [ ] **`:only-of-type`** 〔模糊〕\
  父元素里唯一一个这种类型的元素。
- [ ] **函数式伪类** 〔忘了〕\
  可以接收参数（括号里的选择器列表），表达更复杂的条件。普通伪类如 `:hover` 不带参数。
- [ ] **`:is()`** 〔忘了〕\
  匹配列表里**任意一个**选择器。

  ```css
  :is(ol, ul) li { ... }
  ```

  > 注：`:is()` 的特异性取列表里最高的那个。
- [ ] **`:where()`** 〔忘了〕\
  和 `:is()` 一样匹配列表里任意一个，区别是它的特异性**永远为 0**。
- [ ] **`:has()`** 〔忘了〕\
  俗称「父选择器」：选中**包含**某些后代的元素。

  ```css
  div:has(img) { ... } /* 里面有图片的 div */
  ```
- [ ] **`::marker`** 〔忘了〕\
  选中列表项前面的项目符号或编号。

#### 颜色

- [ ] **`box-shadow`** 〔模糊〕\
  给元素加一个或多个阴影。

  ```css
  box-shadow: offset-x offset-y blur-radius spread-radius color;
  box-shadow: 10px 10px 20px rgba(0, 0, 0, 0.4);
  ```
- [ ] **`inset`** 〔模糊〕\
  加上这个关键字，阴影画在元素**里面**，而不是外面。
- [ ] **多重阴影** 〔忘了〕\
  用逗号分隔多个阴影，从前往后叠：写在前面的在最上层。
- [ ] **径向渐变 `radial-gradient()`** 〔模糊〕\
  从一个中心点向外，呈圆形或椭圆形扩散的渐变。

#### 表单样式

- [ ] **`appearance: none`** 〔模糊〕\
  去掉浏览器给表单元素的默认外观，让你完全掌控样式。代价是要自己保证焦点提示和错误提示仍然存在。

  > 注：它去掉的是「皮」，不动「账本」：`:checked` 之类的状态照样工作。

#### 盒模型

- [ ] **`overflow-x` / `overflow-y`** 〔模糊〕\
  分别控制横向（x 轴）和纵向（y 轴）的溢出。
- [ ] **`translate()`** 〔模糊〕\
  把元素从当前位置移开。

  ```css
  transform: translateY(-6px); /* 负值往上 */
  ```
- [ ] **外边距折叠 · Margin Collapse** 〔模糊〕\
  上下相邻元素的**垂直**外边距会重叠成一个，取两者中**较大**的那个。只发生在上下方向，左右不会。
- [ ] **CSS Reset** 〔忘了〕\
  去掉浏览器默认样式（全部或一部分）的样式表。第三方方案有 `normalize.css`、`sanitize.css`。

#### 弹性盒布局

- [ ] **`flex-flow`** 〔忘了〕\
  `flex-direction` 和 `flex-wrap` 的简写。

  ```css
  flex-flow: row wrap;
  ```
- [ ] **`flex-start` / `flex-end`** 〔模糊〕\
  靠主轴的起点 / 终点。主轴可能是横的，也可能是竖的。
- [ ] **`space-between`** 〔模糊〕\
  首尾两个项目贴边，剩余空间平均分到项目**之间**。
- [ ] **`space-around`** 〔模糊〕\
  每个项目两侧的空间相等，所以首尾的留白只有中间间距的一半。
- [ ] **`align-items: stretch`** 〔模糊〕\
  沿交叉轴拉伸，填满容器。不写 align-items 时就是这个效果。

#### 排版

- [ ] **通用字体族** 〔模糊〕\
  `serif`、`sans-serif`、`monospace`、`cursive`、`fantasy`。
- [ ] **At 规则 · At-rules** 〔忘了〕\
  以 `@` 开头、给浏览器下指令的语句，比如 `@media`、`@keyframes`、`@font-face`。
- [ ] **`@font-face`** 〔模糊〕\
  定义自定义字体：指定字体文件、格式、字重、样式等。必须写 `src` 才有效。

  ```css
  @font-face {
    font-family: "MyFont";
    src: url("myfont.woff2") format("woff2");
  }
  ```
- [ ] **`text-shadow`** 〔模糊〕\
  给文字加阴影。X、Y 偏移**必填**：正值向右、向下，负值向左、向上。

  ```css
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
  ```
- [ ] **多重文字阴影** 〔忘了〕\
  逗号分隔，从前往后叠：第一个在最上层。

#### 无障碍

- [ ] **无障碍树 · Accessibility Tree** 〔模糊〕\
  屏幕阅读器等辅助技术用来理解和操作页面内容的结构。
- [ ] **`max()`** 〔忘了〕\
  返回一组逗号分隔的值里最大的那个。

  ```css
  img { width: max(250px, 25vw); }
  /* 视口窄于 1000px 时取 250px，更宽时取 25vw */
  ```
- [ ] **`.sr-only`** 〔模糊〕\
  常用技巧：视觉上隐藏，但屏幕阅读器**仍然能读到**。

  ```css
  .sr-only {
    position: absolute;
    width: 1px;
    height: 1px;
    padding: 0;
    margin: -1px;
    overflow: hidden;
    clip: rect(0, 0, 0, 0);
    white-space: nowrap;
    border: 0;
  }
  ```
- [ ] **`scroll-behavior: smooth`** 〔模糊〕\
  让页面滚动平滑过渡，比如点锚点链接时。
- [ ] **`prefers-reduced-motion`（媒体特性）** 〔模糊〕\
  检测用户是否在系统里设置了减少动态效果。下面的例子只在用户**没有**这个偏好时才开启平滑滚动。

  ```css
  @media (prefers-reduced-motion: no-preference) {
    * { scroll-behavior: smooth; }
  }
  ```
- [ ] **`aria-hidden="true"`** 〔忘了〕\
  只对辅助技术隐藏：屏幕阅读器不读，视觉上照样显示。适合纯装饰性的图片。

  > 注：fCC 的示例写成了不带值的 `aria-hidden`，规范写法要写成 `aria-hidden="true"`。
- [ ] **`hidden` 属性** 〔忘了〕\
  视觉上和无障碍树里都隐藏，大多数现代浏览器支持，用 JavaScript 很容易切换。
- [ ] **`placeholder` 的问题** 〔忘了〕\
  用户常把占位文字误当成已经填好的值，对无障碍不友好。不要拿它代替 `label`。

#### 定位

- [ ] **清除浮动 `clear`** 〔忘了〕\
  决定元素是否要移到浮动元素的下方。多个浮动元素挨着时可能出现重叠和高度塌陷，所以有了 `clearfix` 技巧。

#### 属性选择器

- [ ] **属性选择器 `[attr]`** 〔模糊〕\
  按 HTML 属性选中元素，比如 `href`、`title`。

  ```css
  [title] { ... }              /* 有 title 属性 */
  a[href="https://x.com"]     /* 完全等于 */
  a[href^="https"]            /* 以 https 开头 */
  a[href$=".pdf"]             /* 以 .pdf 结尾 */
  a[href*="example"]          /* 包含 example */
  ```

#### 响应式设计

- [ ] **响应式设计 · RWD** 〔忘了〕\
  核心是适应性：网站根据设备的屏幕尺寸和能力调整布局和内容。
- [ ] **流式网格 · Fluid Grids** 〔忘了〕\
  用百分比等相对单位代替固定的像素，让内容随屏幕大小缩放、重新排列。
- [ ] **弹性图片 · Flexible Images** 〔忘了〕\
  图片在容器内缩放，小屏幕上不会溢出。
- [ ] **`aspect-ratio`** 〔忘了〕\
  视口的宽高比。
- [ ] **`orientation`** 〔模糊〕\
  设备是横屏 `landscape` 还是竖屏 `portrait`。
- [ ] **`prefers-color-scheme`** 〔模糊〕\
  检测用户在系统里选的是浅色还是深色主题。
- [ ] **逻辑运算符 `and` / `not` / `only`** 〔忘了〕\
  `and` 组合多个媒体特性；`not` 取反；`only` 用来隔离这条查询。

#### 网格

- [ ] **自动放置 `grid-auto-flow`** 〔模糊〕\
  浏览器用自动放置算法摆放项目；`grid-auto-flow` 控制方向（`row`、`column`），`dense` 会回填前面的空洞。
- [ ] **按网格线放置** 〔模糊〕\
  网格线是有编号的。用 `grid-column-start` / `grid-column-end`、`grid-row-start` / `grid-row-end` 指定从哪条线开始、到哪条线结束；简写是 `grid-column`、`grid-row`。

  ```css
  grid-column: 1 / 3; /* 从第 1 条线到第 3 条线，跨 2 列 */
  ```
- [ ] **网格对齐** 〔模糊〕\
  在容器上用 `justify-items`（横向）和 `align-items`（纵向）对齐所有项目；在单个项目上用 `justify-self`、`align-self` 覆盖。

#### 基础 CSS

- [ ] **CSS 是什么** 〔模糊〕 — 层叠样式表（Cascading Style Sheets），给 HTML 元素加样式的语言：颜色、背景图、布局等。

#### 设计

- [ ] **Layout 布局** 〔忘了〕 — 文字、图片、留白等视觉元素在页面上的排列方式。
- [ ] **Alignment 对齐** 〔忘了〕 — 元素彼此之间的位置关系。对齐得当，设计显得整洁有序。
- [ ] **Composition 构图** 〔忘了〕 — 安排元素让整体和谐，决定图片、文字、形状之间如何呼应。
- [ ] **Balance 平衡** 〔忘了〕 — 视觉重量在画面里的分布，可以对称，也可以不对称。
- [ ] **Scale 比例** 〔模糊〕 — 拿一个元素的大小和另一个元素比较。
- [ ] **Hierarchy 层级** 〔忘了〕 — 元素的重要性排序，保证最重要的信息最先被看到。
- [ ] **Contrast 对比** 〔模糊〕 — 用颜色、大小、形状、质感等差异让元素区分明显。强对比也能提高可读性。
- [ ] **White Space 留白** 〔忘了〕 — 也叫负空间，指设计中元素周围的空白区域。
- [ ] **UI 用户界面** 〔模糊〕 — 用户在屏幕上能看到、能操作的元素：图标、图片、文字、菜单、链接、按钮。
- [ ] **UX 用户体验** 〔模糊〕 — 用户使用产品时的感受。好的 UX：直观、易用、高效、无障碍、让人愉快。
- [ ] **Design Brief 设计简报** 〔忘了〕 — 写明项目目标和需求的文档，是设计过程的路线图。
- [ ] **Vector Based Design 矢量设计** 〔忘了〕 — 用数学公式来定义线条、形状和颜色的数字图形创作。
- [ ] **Prototyping 原型** 〔忘了〕 — 给产品或界面做一个可以交互的模型。
- [ ] **视觉层级 · Visual Hierarchy** 〔忘了〕 — 给视线一条清晰路径，让信息按你想要的顺序被读到。
- [ ] **响应式图片 · Responsive Images** 〔忘了〕 — 会随屏幕大小缩放的图片，从桌面到手机都好看。
- [ ] **以用户为中心 · User-centered Design** 〔忘了〕 — 从用户的需求、偏好和限制出发来设计页面。
- [ ] **用户研究 · User Research** 〔模糊〕 — 系统研究使用产品的人，弄清他们的需求、行为和痛点。
- [ ] **A/B 测试** 〔模糊〕 — 把新功能随机推给一部分用户，再用数据分析判断这个功能好不好。
- [ ] **用户需求 · User Requirements** 〔忘了〕 — 应用必须满足的用户故事或标准，可以来自用户研究、行业标准或相关方的意见。
- [ ] **延迟注册 · Deferred/Lazy Registration** 〔模糊〕 — 允许用户不注册就先浏览和使用应用。
- [ ] **深色模式 · Dark Mode** 〔模糊〕 — 把默认浅色配色换成深色。深色模式里应使用**低饱和度**的颜色。
- [ ] **面包屑 · Breadcrumbs** 〔忘了〕 — 显示用户在网站层级中所处位置的导航。放在页面顶部，字号要易读但别太占地方。
- [ ] **卡片组件 · Card** 〔忘了〕 — 设计简洁，别堆太多信息；图片和视频要用高质量素材。
- [ ] **无限滚动 · Infinite Scroll** 〔忘了〕 — 滚到底自动加载更多。可以考虑改用「加载更多」按钮把控制权交给用户，并提供返回按钮。
- [ ] **模态对话框 · Modal Dialog** 〔忘了〕 — 盖在页面上的弹窗，背景通常加一层暗色遮罩；最好允许点击外面关闭。用 HTML 的 `dialog` 元素能自带很多功能和无障碍支持。
- [ ] **表单进度提示** 〔模糊〕 — 告诉用户流程进行到第几步。要简洁、好找，并且能回到上一步。
- [ ] **购物车 · Shopping Cart** 〔忘了〕 — 始终可见，用常见图标（购物车、袋子、篮子），并有清楚的「去结算」按钮。

#### 颜色

- [ ] **色彩理论 · Color Theory** 〔模糊〕 — 研究颜色之间如何相互作用、如何影响人的感受：颜色关系、配色和谐、颜色的心理作用。
- [ ] **二次色 · Secondary Colors** 〔模糊〕 — 两种原色等量混合得到：绿、橙、紫。
- [ ] **三次色 · Tertiary Colors** 〔模糊〕 — 一种原色加上相邻的二次色：黄绿、蓝绿、蓝紫。
- [ ] **类似色 · Analogous** 〔模糊〕 — 色轮上**相邻**的颜色，统一、舒缓。
- [ ] **互补色 · Complementary** 〔模糊〕 — 色轮上**相对**的颜色，对比强烈、冲击力大。
- [ ] **三角色 · Triadic** 〔模糊〕 — 色轮上大致**等距**的三种颜色，连起来是等边三角形，鲜艳活泼。

#### 表单样式

#### 排版

- [ ] **排版 · Typography** 〔模糊〕 — 选择合适的字体和格式，让文字既好看又好读。Type 指每个字符怎样设计、怎样排列。
- [ ] **字型 · Typeface** 〔模糊〕 — 一套字符、数字和符号的整体设计风格，是一个字体家族的「蓝图」。
- [ ] **字体 · Font** 〔模糊〕 — 字型的一个具体变体，有特定的字号、字重、样式和宽度。
- [ ] **字重 · Font Weight** 〔模糊〕 — 笔画的粗细，比如 light、regular、bold、black。
- [ ] **字体样式 · Font Style** 〔模糊〕 — 字符的倾斜方式，比如 italic、oblique。
- [ ] **字宽 · Font Width** 〔模糊〕 — 字符占的水平空间，比如 condensed（窄）、expanded（宽）。
- [ ] **x 高度 · X-height** 〔模糊〕 — 小写字母的平均高度，不算上伸部和下伸部。
- [ ] **字偶距 · Kerning** 〔模糊〕 — 调整**某一对**特定字符之间的间距，比如缩小 A 和 V 之间的空隙。
- [ ] **排版最佳实践** 〔忘了〕 — 正文用清晰简单的字体；全站最多用两三种字体（太多会难读、削弱品牌、拖慢加载）；用字号区分标题、副标题、正文，建立层级。
- [ ] **Web 安全字体 · Web Safe Fonts** 〔模糊〕 — 几乎所有设备都装了的字体。浏览器在用户系统里找不到指定字体时，会退回系统默认字体。无衬线：Arial、Verdana、Trebuchet MS；衬线：Times New Roman、Georgia。
- [ ] **字体格式 `format()`** 〔模糊〕 — 可选，提示浏览器字体是什么格式。不写就先下载再识别；写了无效格式则不下载。可选值有 `woff`、`woff2`、`truetype`、`opentype` 等。
- [ ] **`woff` / `woff2`** 〔模糊〕 — Web 开放字体格式（Web Open Font Format），由 Mozilla 等合作开发。两者的区别在压缩算法。
- [ ] **OpenType** 〔忘了〕 — 微软和 Adobe 开发的可缩放字体格式，能用上字体里的额外特性，各大系统都支持。
- [ ] **`tech()`** 〔忘了〕 — 可选，声明字体资源用到的技术。
- [ ] **外部字体** 〔模糊〕 — 不在项目文件里、托管在别的服务器上的字体。用 `<link>` 或 CSS 里的 `@import` 引入。
- [ ] **Google Fonts / Font Squirrel** 〔模糊〕 — 两个常用的外部字体来源。Google Fonts 里很多字体是专为网页设计的。
