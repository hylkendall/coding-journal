**卡 1**

正面
```
Is <input disabled="false"> disabled? What rule do boolean attributes follow, and what are the valid ways to write one?
- - - - - - - - - -
<input disabled="false"> 是禁用的吗？布尔属性遵循什么规则？合法的写法有哪几种？
```

背面
```
Yes, it is disabled. A boolean attribute is true when it is present and false only when it is absent; its value is ignored. To make it false, remove the whole attribute. Valid forms: disabled, disabled="", disabled="disabled". "false" is not a valid value (the W3C validator reports it as an error).
- - - - - - - - - -
是禁用的。布尔属性写了就是 true，只有整个不写才是 false，它的值会被忽略。想让它是 false，只能把整个属性删掉。合法写法有三种：disabled、disabled=""、disabled="disabled"。"false" 不是合法值（W3C 验证器会报错）。
```

标签：`html::attributes`

**卡 2**

正面
```
How do you make <b> appear on the page as plain text instead of being treated as a tag? Which entities display <, >, and &?
- - - - - - - - - -
想让 <b> 在页面上原样显示成文字、而不是被浏览器当成标签，该怎么写？<、>、& 分别用哪个实体显示？
```

背面
```
Write it with HTML entities: &lt;b&gt;. &lt; displays <, &gt; displays >, &amp; displays &. Entities let characters that have a special meaning in HTML display as plain text. Every entity starts with &, so to display & itself, write &amp;.
- - - - - - - - - -
用 HTML 实体写：&lt;b&gt;。&lt; 显示 <，&gt; 显示 >，&amp; 显示 &。实体能让在 HTML 里有特殊含义的字符当普通文字显示。每个实体都以 & 开头，所以想显示 & 本身，要写 &amp;。
```

标签：`html::basic`

- - - - - - - - - -
<meta name="description"> 和 Open Graph 标签各管什么？各自用哪个属性写属性名？
```

背面
```

Both go in the head.
- - - - - - - - - -

Open Graph 标签 <meta property="og:..." content="...">：网页链接分享到社交平台（Facebook、LinkedIn 等）时显示成什么样。用的是 property。
两者都写在 head 里。
```

**卡 6**

正面
```
Think of a link inside an iframe that is nested in another iframe. Where does the linked page open with each target value: _self, _parent, _top, _blank?
- - - - - - - - - -
设想一个链接在 iframe 里，这个 iframe 又嵌套在另一个 iframe 里。target 分别是 _self、_parent、_top、_blank 时，链接的页面在哪里打开？
```

背面
```
_self (the default): in the current frame (the same browsing context).
_parent: in the frame that directly contains the current one (one level up).
_top: in the whole browser tab (the top-level browsing context), no matter how many levels deep the link is.
_blank: in a new tab or window.
- - - - - - - - - -
_self（默认值）：在当前这一层框里打开（同一个浏览上下文）。
_parent：在直接装着当前这一层的那一层里打开（往上一层）。
_top：在整个浏览器标签页里打开（最顶层的浏览上下文），不管链接套在第几层。
_blank：在新标签页或新窗口里打开。
```

标签：`html::links`

**卡 8**

正面
```
In a form's method attribute, where does the data go with GET and with POST? Which one should you use for a password?
- - - - - - - - - -
表单的 method 属性用 GET 和用 POST 时，数据分别放在哪里？提交密码该用哪个？
```

背面
```
GET: the data is appended to the URL as ?name=value&name=value and is visible in the address bar. Each name comes from an input's name attribute.
POST: the data is sent in the body of the request, not in the URL.
Use POST for passwords and other sensitive data.
- - - - - - - - - -
GET：数据以 ?名字=值&名字=值 的形式拼在网址后面，地址栏里看得到。每个「名字」来自输入框的 name 属性。
POST：数据放在请求的正文里发送，不在网址里。
密码和其他敏感数据用 POST。
```

标签：`html::forms`

```
