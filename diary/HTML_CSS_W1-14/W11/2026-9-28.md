先说结论：这个研讨会的主线就一件事，**所有颜色都通过变量取，最后媒体查询只改变量，整座城就切成夜景**。其余部分都是「用纯 CSS 画图」的技巧。

## 一、文件结构

**HTML 分两层，每层是一排楼**

- `.background-buildings sky` 是后排楼加天空背景，`.foreground-buildings` 是前排楼。两层都铺满全屏，叠在一起。
- 每栋楼是一个外框（比如 `.bb1`），里面装着从上到下的各个部件（`bb1a`、`bb1b`、`bb1c`……），窗户用 `-window` 结尾。
- 命名规律：`bb` 表示 background building，`fb` 表示 foreground building，`a/b/c/d` 大致按从上到下排。
- 那些空的 `<div></div>` 不是写错了，是用来占位、调节楼间距的（第三部分会讲原理）。
- 一个元素可以挂多个类，比如 `class="bb1 building-wrap"`：前一个类管这栋楼自己的尺寸，后一个类管通用的排列方式。

**CSS 的顺序本身就是一套组织思路**

变量 → 全局重置 → 两层容器 → 工具类 → 天空 → 后排楼 → 前排楼 → 媒体查询（放在最底部）

## 二、三个重点

**1. 变量换肤**

`:root` 里定义了 8 个变量，楼体色 1 到 4 和窗户色 1 到 4 一一配对，所有楼都只通过 `var()` 取色。到了媒体查询里，只要在 `:root` 上把这 8 个变量重新定义一遍，每栋楼不用改一行，整座城就变黑了。

媒体查询必须放在最后，这就是你周六第 2 题钉死的那条：媒体查询不增加优先级，`:root` 对 `:root`，优先级打平，所以后写的生效。

**2. 百分比高度是一条链**

`body` 的 `100vh` → 容器的 `100%` → `.bb1` 的 `70%` → `.bb1d` 的 `70%`。百分比高度必须以父元素有明确的高度为前提，这条链上断掉任何一环，下面的百分比高度就会失效。整座城几乎全用百分比，所以拖动窗口时会跟着等比缩放。

**3. 工具类复用**

`building-wrap` 和 `window-wrap` 就是今天第 62 步那个「新类」。它们把好几栋楼共用的排列方式抽出来，谁需要就挂上谁，不用复制代码。

## 三、用到的技巧清单

**Flex 布局**

- `align-items: flex-end`：所有楼都靠底对齐，看起来像站在地面上。
- `justify-content: space-evenly` 配合空 div：空 div 宽度是 0，但它照样算一个 flex 项目，会参与分配间距，所以能用来撑出额外的空隙。
- `.building-wrap` 用 `column` 加 `center`，把楼的各个部件从上到下居中堆起来。
- `.fb4b` 用 `flex-wrap: wrap` 排圆窗：每扇窗宽 30%，左右 margin 各 10%，一共占 50%，所以一行刚好排两扇，6 扇窗排成 3 行。

**用边框画三角形和梯形**

- 元素本身宽度为 0，底边框上色，左右边框透明，就会出现一个三角形（`.bb2a`、`.fb1a`）。
- 如果元素本身有宽度，同样的写法画出来是梯形（`.fb2a`）。
- 上边框透明、左边框上色，会得到一个直角三角形，用来做斜屋顶（`.fb4a`）。
- 这里的边框宽度用的是 `vh/vw`，没有用 `%`，因为边框宽度根本不接受百分比。你可以去 MDN 查 `border-width` 的 Values 部分，里面只有长度值和 thin、medium、thick 这几个关键字。

**渐变**

- **硬边**：两个颜色写在同一个位置（比如 `6%` 和 `6%`），中间就没有过渡，直接切换颜色。所有条纹窗户都靠这一招。
- **`repeating-linear-gradient`**：把一小段图案重复铺满，默认方向是横条纹，加上 `90deg` 变成竖条纹。
- **多层背景叠加**（`.fb1c`、`.fb5`、`.fb6`）：多层渐变用逗号隔开，写在前面的在上层。上层竖条纹里的 `transparent` 部分像挖了洞，能透出下层的横条纹，两层交叉就成了窗格。
- **径向渐变画太阳**：`circle at 15% 15%` 表示圆心在左上方，`closest-corner` 表示渐变半径算到离圆心最近的那个角。0 到 20% 是实心的太阳，21% 突然变色，这 1% 的差距就形成了太阳的轮廓，之后一直过渡到天空色。另外，第一个颜色不写位置时，默认就是 0%。

**定位**

- 两层容器都是 `absolute` 加 `top: 0`，叠在同一个位置。没有写 `z-index` 时，HTML 里后写的那层画在上面，所以前排楼挡住后排楼。
- `.fb4` 和 `.fb5` 用 `relative` 加 `left/right` 往左右挪了一点。relative 偏移后，元素原来的位置仍然保留，其他楼不会被挤开。

**全局重置和收尾**

- `* { box-sizing: border-box; }` 统一了盒模型的计算方式。
- `body` 设置 `margin: 0`，去掉那个 8px 的默认外边距。
- `overflow: hidden` 把超出屏幕的部分藏起来，不出现滚动条。
- `border-radius: 50%` 把窗户变成圆形。
