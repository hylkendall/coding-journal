## 学了什么:

**总判断法：容器怎么排，还是我被怎么排**

- 写在容器上：`display: grid`、`grid-template-columns`、`grid-template-rows`、`grid-template-areas`、`gap`、`grid-auto-rows` / `grid-auto-columns`
- 写在子项上：`grid-column`、`grid-row`、`grid-area`

**1. Grid 和 Flexbox 的区别**

Grid 是二维的，同时管行和列。Flexbox 是一维的，只沿一条轴排。

**2. `fr` 和百分比**

`fr` 分的是扣掉 gap 和固定尺寸轨道之后**剩下的空间**。百分比按容器**总尺寸**算，不管 gap，所以 `25% × 4` 再加 gap 会溢出，而 `1fr × 4` 不会。别拿"弹性"当区分标准，两者都会跟着容器缩放。

**3. `gap`**

`gap` 只加在轨道之间，不加在网格外边缘。`gap: 行间距 列间距`，也可以分开写成 `row-gap` 和 `column-gap`。

**4. `repeat()`**

`repeat(次数, 尺寸)` 是省事写法，`repeat(3, 1fr)` 等于 `1fr 1fr 1fr`。它只是省去重复书写，行数或列数还是你定死的。

**5. 显式网格和隐式网格**

- 显式：由 template 系列属性定义，**写几个值就是几条轨道**。`grid-template-rows: 100px` 的意思是"只有一行"，不是"每行 100px"。
- 隐式：子项放不下时浏览器自动补出来的轨道，默认高度由内容撑开，用 `grid-auto-rows` / `grid-auto-columns` 统一设置。
- 本质区别在**行数由谁决定**：显式是你定，隐式是内容定。只写列、不写行的时候，每一行都是隐式的。
- 验证技巧：改一下内容大小，高度跟着变的就是隐式行。

**6. `minmax()`**

`minmax(最小, 最大)` 给轨道设一个尺寸范围。之前记的钩子答案在这里：`1fr` 单独写时，等价于 `minmax(auto, 1fr)`，最小值是内容的最小尺寸，所以长内容能把列撑开。想严格均分就写 `minmax(0, 1fr)`。

**7. `grid-column` 和 `grid-row`**

- 语法是 `起始线 / 结束线`。线的编号从 1 开始，n 列有 n+1 条线。
- `span n` 表示跨 n 格，`1 / 3` 和 `1 / span 2` 效果相同。
- 子项占的格子多了，其他子项会被挤到后面，可能挤出隐式行。
- Safari 检查器的"布局"面板能打开网格叠加层，直接看到线的编号。

**8. `grid-template-areas` 和 `grid-area`**

容器用 `grid-template-areas` 画地图、给区域起名，子项用 `grid-area: 名字` 去认领区域。规则如下：

- 一个带引号的字符串是一行，里面每个词是一格。
- 相邻格子写同一个名字，就合并成一个区域。
- 字符串里的名字带引号，`grid-area` 后面的名字不带引号。
- 留空用 "."，连着写的几个点也只算一格，可以用来对齐。
- 每行格子数必须相同，每个区域必须是矩形。违反任何一条，整句声明失效，所有子项会叠在一起。你用"上下两块都叫 1"的实验亲眼验证过。
- 区域名用字母开头，因为 `grid-area: 1` 会被当成网格线编号。
- 写了几个字符串，就定义了几行显式行。
