## 一、什么是响应式设计?跟 Grid/Flexbox 什么关系?
（对应理论第 1 问）

- **定义**：**一套代码**自动适应所有屏幕尺寸,而不是给手机/平板/电脑各做一个版本。
- **为什么要**：设备尺寸太碎了（各种手机、平板、笔记本、大屏显示器）,不可能一个个适配。
- **经典三支柱**（响应式的三个组成部分,记这个框架）：
  1. 流式布局（用相对单位 %、fr,而非写死 px）
  2. 弹性图片（图片能跟着容器缩放,如 `max-width: 100%`）
  3. 媒体查询（下面第二块）
- **跟 Grid/Flexbox 的关系**：它俩是实现"流式布局"的**主力工具**——本身就会自动伸缩排列。可以说 **Grid/Flexbox 负责"平滑适应",媒体查询负责"到点切换"**,两者配合才完整。

## 二、媒体查询怎么工作?常见媒体类型和特性?
（对应理论第 2 问,这块最需要花时间）

- **本质**：一个 CSS 里的 **if 判断**——"如果屏幕满足某条件,就应用这套样式"。
- **完整语法结构**：
  ```
  @media 媒体类型 and (媒体特性) { 样式规则 }
  ```

**① 媒体类型（media type）** —— 核心必抓
- `screen`：屏幕（最常用,手机电脑都算）
- `print`：打印时
- `all`：所有类型（默认,可省略）
- （其余如 speech 基本弃用,不用管）

**② 逻辑运算符** —— 核心必抓
- `and`：同时满足（`screen and (max-width: 768px)`）
- `,`（逗号）：满足任一即可（= or）
- `not`：取反
- `only`：⭐ 老浏览器兼容用,见过即可

**③ 媒体特性（media feature）** —— 只有前两个是核心,其余⭐扫一眼
- ⭐核心⭐ `min-width` / `max-width`：屏幕宽度阈值（**响应式 90% 靠这个**）
- ⭐核心⭐ `orientation`：横屏 `landscape` / 竖屏 `portrait`（你刚搞懂那个,按宽高比判断）
- `min-height` / `max-height`：高度阈值（少用）
- `aspect-ratio`：宽高比
- `resolution`：屏幕清晰度/DPI（高清屏适配）
- `hover` / `pointer`：能否悬停、指针精度（区分触屏和鼠标）
- `prefers-color-scheme`：深色/浅色模式
- `prefers-reduced-motion`：用户是否要求减少动画

> 后 6 个现在**不用背**,知道"媒体特性不止宽度,还能查横竖、清晰度、深色模式……"这个**范围感**就够了。

## 三、什么是断点?现代常见断点?
（对应理论第 3 问）

- **定义**：媒体查询里那个用来"换挡"的**具体宽度值**——布局在这个宽度上切换方案。
- **常见档位**（记"小/中/大"三档感觉即可）：
  - 手机：~576px 以下
  - 平板：~768px
  - 桌面：~992px / ~1024px
  - 大屏：~1200px 以上
- ⚠️ **最重要的一句**：这些数字是**行业惯例,不是标准规定**。每个框架自己定一套（Bootstrap 一套、Tailwind 一套）。**别死背具体数字**,现代更推荐"看内容在哪挤坏了就在哪设断点"（基于内容,而非基于某台设备）。

## 四、什么是移动优先(mobile-first)?
（对应理论第 4 问）

- **定义**：**先写窄屏（手机）的基础样式**（不放进任何媒体查询）,再用 `min-width` 随屏幕变大**逐级往上加**东西。
- **对比**：
  - 移动优先 → 基础样式 + `min-width` 向上增强（现代默认✅）
  - 桌面优先 → 基础样式 + `max-width` 向下削减
- **为什么用移动优先**：
  1. 性能——手机先加载最精简的样式
  2. 思路清晰——从最核心内容出发,逐步"渐进增强"
  3. 移动端流量占大头
- **代码方向长这样**：
  ```css
  /* 基础：窄屏,不写 media query */
  .box { flex-direction: column; }
  /* 屏幕变宽了,再加 */
  @media (min-width: 768px) {
    .box { flex-direction: row; }
  }
  ```

---

**一张纸的总纲**（贴墙上）：

> 目标 = 一套代码适应所有屏（第一块）→ 平滑适应靠 Grid/Flexbox/相对单位 → 到点切换靠媒体查询（第二块）→ 切换的那个宽度叫断点（第三块）→ 写切换时从窄往宽加 = 移动优先（第四块）。
