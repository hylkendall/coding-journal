# 2026-8-31(W7D1)
## 今日主题:设计特征选择页面、表单样式复习

## 卡壳的点:
卡 1
正面:appearance: none 用在表单控件上,移除的是什么?
背面:元素的默认外观样式(checkbox 的方框、下拉框的箭头、radio 的圆圈等),不止是颜色。功能状态不受影响。
标签:CSS::表单样式

卡 2
正面:表单控件用了 appearance: none 后,必须自己补回哪两类标识?为什么?
背面:焦点标识(:focus)和错误标识。键盘/读屏用户靠它们知道当前停在哪、哪里填错了,属无障碍硬需求。
标签:CSS::表单样式

卡 
正面:WebKit 是什么?
背面:一种浏览器引擎(负责把网页渲染显示出来),Safari 使用它。与 CSS 属性无关;-webkit- 前缀即为它服务。
标签:CSS::浏览器与引擎
