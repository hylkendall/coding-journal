## 今日主题:排版： CSS字体
## 学了什么:

**1–2. 排印基础与最佳实践**
- 可读性的三个主控:`font-size`、`line-height`、行长(一行多少字符)。英文正文的经验值是每行 45–75 字符。
- `line-height` **带单位和不带单位是两回事**。这是本节唯一的硬陷阱,下面有实验。
- 建立视觉层级优先用字号和字重,不是靠颜色。

**3. 字体家族**
- `font-family` 的值是一条**回退链**,浏览器从左往右找,用第一个能拿到的。
- 链尾必须放通用族(`serif` / `sans-serif` / `monospace` / `cursive` / `fantasy`),这是最后的兜底。
- 字体名含空格要加引号:`"Times New Roman"`。
- 回退是**逐字形**发生的,不是整段一起换——某个字符前面的字体没有,只有这个字符掉到下一级。

**4. 网页安全字体**
- 指"绝大多数系统预装、可以不下载直接用"的那批:Arial、Georgia、Times New Roman、Courier New、Verdana 、Trebuchet MS(小写L的可辨识度高)等。
- 它是个历史概念,今天主要作为回退链的中间层存在。

**5. `@font-face`**
- 它做的事是**登记**:给一个字体文件起个 `font-family` 名字,告诉浏览器去哪儿 `src` 拿。
- **登记 ≠ 应用**。写完 `@font-face` 那个字体不会自己出现在页面上,你还得在某条规则里 `font-family: 那个名字`。这跟你熟的账本/画皮是同一类区分:登记进账本,不等于画到皮上。

**6. 外部字体**
- Google Fonts 两种接法:HTML 里 `<link>`,或 CSS 里 `@import`。`<link>` 是推荐做法。
- 接进来之后仍然是普通的 `font-family` 用法,没有特殊语法。

**7. `text-shadow`**
- 语法:`text-shadow: 水平偏移 垂直偏移 模糊半径 颜色;`
- 前两个必填,后两个可选(模糊默认 `0`,颜色默认取当前文字颜色)。
- 逗号分隔可以叠多层阴影。
- 它**不占布局空间**,阴影再大也不会把旁边的元素挤开。


## 卡壳的点:
正面:为什么正文的 line-height 推荐使用无单位数值?
背面:避免带单位的计算结果被 font-size 不同的后代元素继承,导致大字号文本的行高被压缩、行间重叠。
