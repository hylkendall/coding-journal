**卡 1**
正面：
How is the specificity of `:is(...)` calculated? Does it depend on which item actually matched, or on whether that item exists on the page?
`:is(...)` 的特异性怎么算？跟实际匹配上的是哪一项有没有关系？跟那一项在页面上存不存在有没有关系？
背面：
`:is()` takes the specificity of the single most specific comma-separated item inside its parentheses. The items' scores are not added together, but the parts within one item do add up (`#a .b` counts as 1 id + 1 class). The result depends only on the selector text, not on which item matched or whether it exists on the page. Example: `.list :is(#main, .item)` = 1 id + 1 class, even when it matches through `.item`. A plain list `.list #main, .list .item` is different: each selector is scored separately.
`:is()` 的特异性取括号里用逗号隔开的各项中最高的那一项。各项之间不相加，但同一项内部照常相加（`#a .b` 算 1 个 id 加 1 个 class）。结果只看选择器怎么写，跟实际匹配上的是哪一项无关，跟那一项在页面上存不存在也无关。例：`.list :is(#main, .item)` 算 1 个 id 加 1 个 class，即使实际是靠 `.item` 匹配上的。普通逗号列表 `.list #main, .list .item` 不一样，两条各算各的分。
标签：`css::selectors css::specificity`

**卡 2**
正面：
An element has the `hidden` attribute, and your CSS sets `display: flex` on it. Is it visible? Why?
一个元素带有 `hidden` 属性，你的 CSS 又给它写了 `display: flex`。它看得见吗？为什么？
背面：
Yes, it is visible. `hidden` hides the element only through the browser's default stylesheet, which gives it `display: none`. Your own styles always take precedence over the browser's default stylesheet, regardless of specificity, so any `display` you set overrides it. This is why many CSS resets add `[hidden] { display: none !important; }`.
看得见。`hidden` 隐藏元素，靠的只是浏览器默认样式表给它的 `display: none`。你自己写的样式总是优先于浏览器默认样式表，跟特异性无关，所以你写的任何 `display` 都会把它压掉。这也是很多 CSS Reset 要加上 `[hidden] { display: none !important; }` 的原因。
标签：`css::cascade css::accessibility`

**卡 3**
正面：
Compare three ways of hiding: the `hidden` attribute, `aria-hidden="true"`, and a visually-hidden class (`sr-only`). For each one: is the element visible on screen, and do screen readers read it?
比较三种隐藏方式：`hidden` 属性、`aria-hidden="true"`、视觉隐藏类（`sr-only`）。每一种分别回答：屏幕上看得见吗？读屏软件会读吗？
背面：
`hidden`: not visible, not read (as long as CSS doesn't override its `display: none`).
`aria-hidden="true"`: visible, not read.
`sr-only` class: not visible, read.
A normal element is visible and read.
`hidden`：看不见，也不读（前提是 CSS 没有压掉它的 `display: none`）。
`aria-hidden="true"`：看得见，但不读。
`sr-only` 类：看不见，但会读。
普通元素：看得见，也会读。
标签：`css::accessibility`

**卡 7**
正面：
In `width: max(300px, 50%)`, does `max()` set an upper limit or a lower limit on the width? What does `width: min(300px, 50%)` do?
在 `width: max(300px, 50%)` 里，`max()` 给宽度定的是上限还是下限？`width: min(300px, 50%)` 又是什么效果？
背面：
`max()` picks the larger value, so the width is never smaller than 300px: it sets a lower limit. `min()` picks the smaller value, so the width never exceeds 300px: it sets an upper limit. Each name is the opposite of the limit it sets.
`max()` 取较大的值，所以宽度永远不会小于 300px，定的是下限。`min()` 取较小的值，所以宽度永远不会超过 300px，定的是上限。两个函数的名字都和它定的限正好相反。
标签：`css::units`

**卡 8**
正面：
When does `aspect-ratio: 16 / 9` take effect, and when is it ignored?
`aspect-ratio: 16 / 9` 什么时候起作用，什么时候不起作用？
背面：
It takes effect only when at least one of `width` and `height` is `auto`. The browser then calculates that dimension from the other one and the ratio. If both `width` and `height` are set explicitly, `aspect-ratio` is ignored.
只有当 `width` 和 `height` 至少有一个是 `auto` 时才起作用，浏览器会根据另一边和比例算出这一边。如果 `width` 和 `height` 都写死了，`aspect-ratio` 不起作用。
标签：`css::responsive`

**卡 9**
正面：
In `@media not screen and (min-width: 600px)`, what does `not` negate? On a screen, when do the styles apply? When printing?
在 `@media not screen and (min-width: 600px)` 里，`not` 否定的是哪一部分？在屏幕上，样式什么时候生效？打印时呢？
背面：
`not` negates the entire query: NOT (screen AND width ≥ 600px). On a screen, `screen` is always true, so the styles apply when the width is less than 600px. When printing, `screen` is false, so the styles always apply, whatever the width.
`not` 否定的是整句：不是（屏幕设备，而且宽度 ≥ 600px）。在屏幕上 `screen` 永远成立，所以样式在宽度小于 600px 时生效。打印时 `screen` 不成立，所以不管多宽，样式都生效。
标签：`css::media-queries`

**卡 11**
正面：
Which two properties does `flex-flow` combine? With `flex-flow: row nowrap`, what happens when the items' total width is larger than the container?
`flex-flow` 合并了哪两个属性？在 `flex-flow: row nowrap` 下，如果项目加起来比容器宽，会发生什么？
背面：
`flex-flow` is shorthand for `flex-direction` + `flex-wrap` (e.g. `flex-flow: row-reverse wrap`). With `nowrap`, the items first shrink to fit, because flex items can shrink by default (`flex-shrink: 1`). They overflow the container only when they can't shrink any further, or when `flex-shrink: 0` is set.
`flex-flow` 是 `flex-direction` 加 `flex-wrap` 的简写（例：`flex-flow: row-reverse wrap`）。在 `nowrap` 下，项目先被挤窄来塞进容器，因为 flex 项目默认可以收缩（`flex-shrink: 1`）。只有挤到不能再窄，或者设置了 `flex-shrink: 0` 时，才会溢出容器。
标签：`css::flexbox`

**卡 12**
正面：
In `box-shadow: 0 0 0 8px blue, 0 0 0 4px red;`, which shadow is drawn on top? Can you see the red?
在 `box-shadow: 0 0 0 8px blue, 0 0 0 4px red;` 里，哪层阴影在最上面？能看到红色吗？
背面：
The first shadow in the comma-separated list is drawn on top, and later ones go underneath. Blue (8px spread) is on top and completely covers red (4px spread), so the red is not visible. Swapping the order shows a red inner ring and a blue outer ring. `text-shadow` and multiple backgrounds follow the same rule.
逗号列表里第一层阴影画在最上面，后面的依次往下压。蓝色（扩展 8px）在上面，把红色（扩展 4px）完全盖住，所以看不到红色。把两段对调，就会看到里圈红、外圈蓝。`text-shadow` 和多重背景也是同一个规则。
标签：`css::shadows`

**卡 14a**
正面：
Why should a CSS reset be placed at the very top of your stylesheet?
为什么 CSS Reset 要放在样式表的最前面？
背面：
A reset only sets a baseline, and its rules mostly use low-specificity selectors (`*`, element names). Placed first, any of your later rules with equal or higher specificity overrides it. Placed last, it would override your own rules of equal specificity, such as wiping out your `body { margin: 20px; }`.
Reset 只是打一个底，它的规则大多用低特异性的选择器（`*`、元素名）。放在最前面，你后面写的、特异性相同或更高的规则都能覆盖它。如果放在最后，它会反过来覆盖你写的同等特异性的规则，比如把你的 `body { margin: 20px; }` 清掉。
标签：`css::reset css::cascade`

**卡 14b**
正面：
Why is there a small gap below an `<img>` inside a container by default, and which declaration in a typical CSS reset removes it?
容器里的 `<img>` 底部默认为什么有一条小缝？常见的 CSS Reset 用哪条声明去掉它？
背面：
`<img>` is an inline element by default, so it sits on the text baseline. Below the baseline, the line reserves space for the descenders of letters like g and y, and that space is the gap. `img { display: block; }` takes the image out of the line of text, which removes the gap.
`<img>` 默认是行内元素，会坐在文字的基线上。基线下面要给 g、y 这类字母的下半截留出位置，这段空间就是那条缝。`img { display: block; }` 让图片不再排在文字行里，缝就没了。
标签：`css::reset`
