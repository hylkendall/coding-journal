**卡 1**

正面：
You want an animation to pause on hover and write `.ball:hover { animation: paused; }`. What actually happens, and why? What should you write instead?
┈┈┈┈┈┈┈┈┈┈
想让动画在悬停时暂停，写了 `.ball:hover { animation: paused; }`。实际会发生什么？为什么？应该怎么写？

背面：
The animation is removed entirely: on hover the ball jumps back to its un-animated position, and when the mouse leaves, the animation restarts from the beginning. Reason: a shorthand resets every sub-property you didn't write to its initial value, so `animation-name` becomes `none`. Correct: `animation-play-state: paused;`. Shorthands all follow this rule, e.g. `background: red` resets `background-image`.
┈┈┈┈┈┈┈┈┈┈
动画整个被拿掉：悬停时球跳回没有动画时的位置，鼠标移开后动画从头重新播。原因：简写会把你没写的子属性全部重置成初始值，`animation-name` 变成了 `none`。正确写法：`animation-play-state: paused;`。简写都遵守这条规则，比如 `background: red` 会把 `background-image` 重置掉。

标签：`css::animation css::syntax`

**卡 2**

正面：
In `@media screen and (min-width: 600px), print { ... }`, when do the rules apply? In `@media not screen and (min-width: 600px)`, what exactly does `not` negate?
┈┈┈┈┈┈┈┈┈┈
`@media screen and (min-width: 600px), print { ... }` 里的规则什么时候生效？`@media not screen and (min-width: 600px)` 里的 `not` 否定的是哪一部分？

背面：
The comma means OR, and each part is checked on its own. So the first query applies on a screen at least 600px wide, OR whenever printing (width doesn't matter then). `not` negates the whole query up to the next comma: NOT (screen AND at least 600px wide). It does not negate only `screen`.
┈┈┈┈┈┈┈┈┈┈
逗号是「或」，前后各段独立判断。所以第一条在「屏幕且宽度 ≥ 600px」时生效，或者在打印时生效（打印时不看宽度）。`not` 否定的是到下一个逗号为止的整段查询，也就是「不是（屏幕且宽度 ≥ 600px）」，不是只否定 `screen`。

标签：`css::media-queries`

**卡 3**

正面：
Write the media query that matches (a) a user whose system is in dark mode, and (b) a user who turned on "reduce motion" in system settings. Which values does each media feature accept?
┈┈┈┈┈┈┈┈┈┈
写出媒体查询：(a) 用户系统开了深色模式；(b) 用户在系统设置里开了「减少动态效果」。这两个媒体特性各接受哪些值？

背面：
(a) `@media (prefers-color-scheme: dark)`; values: `light`, `dark`. (b) `@media (prefers-reduced-motion: reduce)`; values: `no-preference`, `reduce`. Both start with `prefers-`, meaning "the user prefers…".
┈┈┈┈┈┈┈┈┈┈
(a) `@media (prefers-color-scheme: dark)`，值：`light`、`dark`。(b) `@media (prefers-reduced-motion: reduce)`，值：`no-preference`、`reduce`。两个都以 `prefers-` 开头，意思是「用户偏好……」。

标签：`css::media-queries css::accessibility`

**卡 4**

正面：
Compare the HTML `hidden` attribute with the CSS `visibility: hidden`: is the element visible, does it still take up space, and do screen readers read it? Where does the `hidden` attribute's effect come from?
┈┈┈┈┈┈┈┈┈┈
对比 HTML 的 `hidden` 属性和 CSS 的 `visibility: hidden`：元素看不看得见？还占不占位置？读屏软件读不读？`hidden` 属性的效果是从哪来的？

背面：
`hidden` attribute: invisible, takes no space, not read. Its effect comes from a rule in the browser's default stylesheet that sets `display: none` (select the element and you can see that rule in Safari's styles panel). `visibility: hidden`: invisible, but still takes up its space; also not read by screen readers.
┈┈┈┈┈┈┈┈┈┈
`hidden` 属性：看不见、不占位置、读屏不读。效果来自浏览器默认样式表里一条设置 `display: none` 的规则（选中元素后在 Safari 的样式面板里能看到）。`visibility: hidden`：看不见，但仍然占着原来的位置；读屏同样不读。

标签：`html css::accessibility`

**卡 5**

正面：
How do you tell whether a pseudo-class is a "tree-structural pseudo-class"? Which of these are: `:hover`, `:first-child`, `:empty`, `:checked`, `:nth-child(2)`, `:target`?
┈┈┈┈┈┈┈┈┈┈
怎么判断一个伪类是不是「树结构伪类」？下面哪些是：`:hover`、`:first-child`、`:empty`、`:checked`、`:nth-child(2)`、`:target`？

背面：
Test: it only looks at the element's position in the document tree (which child it is, whether it is the only one, whether it has content). It does not look at attributes, user actions, form state or the URL. Tree-structural: `:first-child`, `:empty`, `:nth-child(2)`. Not: `:hover` (user action), `:checked` (form state), `:target` (URL).
┈┈┈┈┈┈┈┈┈┈
判断法：只看元素在文档树里的位置关系（排第几个、是不是唯一一个、有没有内容），不看属性、用户操作、表单状态或网址。是树结构伪类的：`:first-child`、`:empty`、`:nth-child(2)`。不是的：`:hover`（用户操作）、`:checked`（表单状态）、`:target`（网址）。

标签：`css::selectors`

**卡 6**

正面：
When does an element match `:target`?
┈┈┈┈┈┈┈┈┈┈
一个元素什么时候匹配 `:target`？

背面：
When the part of the URL after `#` equals that element's `id`. Example: clicking `<a href="#faq">` changes the URL to `...#faq`, so the element with `id="faq"` matches.
┈┈┈┈┈┈┈┈┈┈
网址 `#` 后面的部分等于这个元素的 `id` 时。例：点击 `<a href="#faq">`，网址变成 `...#faq`，于是 `id="faq"` 的元素匹配。

标签：`css::selectors`

**卡 7**

正面：
What two things must every `@font-face` rule contain, and what does each one do?
┈┈┈┈┈┈┈┈┈┈
每条 `@font-face` 规则必须写哪两样？各自的作用是什么？

背面：
`font-family`: the name you give the font; you then use that name in a normal `font-family` declaration. `src`: where the font file is, e.g. `url("myfont.woff2") format("woff2")`. Mnemonic: give it a name + give it an address.
┈┈┈┈┈┈┈┈┈┈
`font-family`：你给这个字体起的名字，之后在普通的 `font-family` 声明里用这个名字。`src`：字体文件在哪，例如 `url("myfont.woff2") format("woff2")`。记法：起名字 + 给地址。

标签：`css::typography`

**卡 8**

正面：
What does `float: left` do to the content after it? What does adding `clear: both` to a later element change?
┈┈┈┈┈┈┈┈┈┈
`float: left` 对它后面的内容有什么影响？给后面的元素加 `clear: both` 会改变什么？

背面：
The floated element moves to the left edge, and the text after it wraps around its right side (like a picture in a newspaper). `clear: both` makes that element refuse to sit beside any earlier float on either side: it moves down below them before it starts. `clear: left` / `clear: right` clear only that side. Typical use: stop the next heading from wrapping around a floated image.
┈┈┈┈┈┈┈┈┈┈
浮动元素靠到左边，后面的文字绕着它的右边排（像报纸里的图片）。`clear: both` 让这个元素不跟它前面左右任一侧的浮动元素并排，挪到它们下面才开始。`clear: left` / `clear: right` 只清对应那一侧。典型用法：不让下一节的标题继续绕着浮动图片排。

标签：`css::positioning`

**卡 9**

正面：
Describe how the speed changes over time for `ease-in`, `ease-out` and `linear`.
┈┈┈┈┈┈┈┈┈┈
`ease-in`、`ease-out`、`linear` 的速度分别是怎么变化的？

背面：
`ease-in`: slow at the start, then speeds up. `ease-out`: fast at the start, slows down at the end. `linear`: constant speed. Mnemonic: "in" = entering, so the slow part is at the start.
┈┈┈┈┈┈┈┈┈┈
`ease-in`：开头慢，然后加速。`ease-out`：开头快，收尾减速。`linear`：匀速。记法：`in` 是「进场」，慢的部分在开头。

标签：`css::animation`
