## 今日主题:CSS变量
## 学了什么:

**一、变量本身怎么定义、怎么用**
- 定义 `--名字: 值;`,取用 `var(--名字)`。存值 → 贴过去。
- 名字必须 `--` 开头,**大小写敏感**(`--Main` ≠ `--main`)。
- 定义在哪个选择器上,作用域就是**那个元素 + 它的后代**,别处用不了。
- 自定义属性**默认继承**,跟 line-height 同一套继承链往下传。
- 写在 `:root {}` = 全局,原因是 :root 是所有元素的祖先,继承下去人人拿得到,不是魔法。
- 能装几乎任何值:颜色、长度、数字,甚至一段值的片段。

**二、var() 的备胎(回退参数)**
- `var(--x, 备胎)`:逗号后面是备胎。
- 触发条件只有一个:**`--x` 没定义**时才用。定义了就永远用定义值,备胎晾一边。
- 备胎能嵌套:`var(--x, var(--y, red))`。
- 第一个逗号之后全算备胎(所以备胎里能含逗号)。

**三、⚠️ 补洞 + 修正我早上说的"整行作废"**
- 场景:`var(--x)` **没定义又没备胎**,或替换完整体是无效值。
- 该属性叫"计算值时无效",它**不是**"这行忽略、保留旧值",而是——**可继承 → 取继承值;不可继承 → 取初始值**。
- 例:`padding: var(--padding)`,`--padding` 是 `香蕉`。padding 不可继承 → 变成初始值 **0**,不是保留原 padding。早上"整行作废"不准,更新成"退回初始/继承值"。

**四、@property(进阶,gist,别手写)**
- 作用:给某个变量注册"类型 + 是否继承 + 默认值"。
- 三个描述符:`syntax`(必填)、`inherits`(必填,true/false)、`initial-value`(syntax 不是 `'*'` 时必填,即默认/兜底值)。
- **`syntax` 常用类型**:
  - `'<length>'` 长度(px、em、rem、vh)
  - `'<color>'` 颜色
  - `'<number>'` 数字(无单位,如 1.5)
  - `'<integer>'` 整数
  - `'<percentage>'` 百分比
  - `'<length-percentage>'` 长度或百分比都收
  - `'<angle>'` 角度(deg、rad)
  - `'<time>'` 时间(s、ms)
- **其余(知道有就行)**:`'<image>'`、`'<url>'`、`'<resolution>'`、`'<transform-function>'`、`'<transform-list>'`、`'<custom-ident>'`、`'<string>'` 等——完整权威清单查 MDN `@property` / `syntax`。
- **组合写法**:
  - `'<length> | <percentage>'` —— 竖线 = "或";也能直接列关键字,如 `'auto | small | large'`
  - `'<length>+'` —— 加号 = 空格分隔的一串(如 `10px 20px`)
  - `'<color>#'` —— 井号 = 逗号分隔的一串
  - `'*'` —— 万能,任何值都收,不做类型检查
- 好处叫**类型安全**:变量被塞了**类型不对**的值、或**没赋值** → 直接用 `initial-value` 顶,轮不到第三条的 IACVT。
- (补一句,以后 JS 阶段再碰:@property 也能用 JS 的 `CSS.registerProperty()` 注册,同一回事。)

**五、三个"兜底"彻底分清(今天核心防坑)**

| 机制 | 在哪一层 | 什么时候触发 |
|---|---|---|
| `var(--x, 备胎)` | 取用点 | `--x` **没定义** |
| `@property` 的 `initial-value` | 变量本身 | 值**类型错**或**缺值** |
| IACVT(继承值/初始值) | 属性本身 | 上面两个都没兜住、var() 最终无效 |

三个都跟**级联、权限高低无关**。级联是另一层,只管"多处给同一变量赋值,谁赢"。

钩子(先记一行,以后用):@property 注册了类型后,变量才能做**动画/过渡**插值,到「动画」模块用得上。
