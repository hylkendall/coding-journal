## W17D4 总结（11/12）

**一、冷启动**

1. `switch` 用 `===` 比较：`case 3:` 匹配不上字符串 `"3"`。哪个 `case` 都没匹配上，`switch` 直接跳过，变量不变。叠在一起的空 `case` 共用同一段代码。
2. `if / else if` 要从严到宽排：`>= 60` 放在 `>= 90` 前面，95 分会被第一档截走。`Number("ninety")` 是 `NaN`，`typeof NaN` 是 `"number"`。

**二、闰年计算器 lab ✅**

1. 读题：英文 "Unless the year is also divisible by 100, then it is not a leap year" 意思是"例外：如果还能被 100 整除，那就不是"。中文译成"除非……否则……"，这个句式是"不满足才怎样"，把逻辑翻反了。中文题干读着矛盾时，对照英文原文。
2. 闰年规则是三层：能被 4 整除 → 是；但还能被 100 整除 → 不是；但还能被 400 整除 → 又是。1900 不是，2000 是。（原因：一年约 365.2422 天，每 4 年补一天补多了，每 100 年扣回一次，扣过头了，每 400 年再补。）
3. "能整除"就是余数为 0：`year % 4 === 0`。
4. 削 `else if` 链：能走到某一档，说明前面所有条件都是 `false`，这些不用再查。最后一档的条件一定成立，写 `else`，顺带保证每条路都有 `return`。还是昨天那个习惯："删掉它，结果会变吗？"

**三、截断字符串 lab ✅**

1. `str.slice(0, num)` 取前 `num` 个字符（从下标 0 到下标 `num` 之前）。
2. `"..."` 接在后面，不算在 `num` 里：`truncateString("A-", 1)` 是 `"A..."`。
3. 长度大于 `num` 才截，小于或等于就原样返回。

**四、字符串结尾检查器 lab ✅**

1. 负数下标从末尾往回数：`slice(-4)` 取最后 4 个字符。
2. `str.slice(-target.length) === target`：截一段和目标一样长的尾巴来比，比较结果直接 `return`。
3. fCC 有一条测试会监视你有没有调用 `.endsWith()`，用了就不过。

**五、代码风格**

1. 函数名和括号之间不留空格：`isLeapYear(num)`；`;`、`)` 前面也不留。
2. 形参名用完整单词说清它是什么（`target`、`ending`），少用别人要猜的缩写（`ckstr`）。

**卡 1**

正面：
```javascript
function isLeapYear(num) {
  if (num % 4 !== 0) {
    return num + " is not a leap year.";
  } else if (num % 100 !== 0) {
    return num + " is a leap year.";
  } else if (num % 400 !== 0) {
    return num + " is not a leap year.";
  } else {
    return num + " is a leap year.";
  }
}
```
1. In JavaScript, how do you write the condition "`num` is divisible by 4"?
2. State the leap-year rule in three layers. Is 1900 a leap year? Is 2000?
3. a. The second branch checks only `num % 100 !== 0`, not also `num % 4 === 0`. Why is that enough?
   b. Why can the last branch be a plain `else` instead of `else if (num % 400 === 0)`?

┄┄┄┄┄┄┄┄

1. 用 JavaScript 怎么写"`num` 能被 4 整除"这个条件？
2. 按三层说出闰年规则。1900 年是闰年吗？2000 年呢？
3. a. 第二个分支只判断 `num % 100 !== 0`，没有再判断 `num % 4 === 0`。为什么这样就够了？
   b. 为什么最后一个分支可以直接写 `else`，不用写 `else if (num % 400 === 0)`？

背面：
1. `num % 4 === 0`. `%` returns the remainder after division, and "divisible" means the remainder is `0`.
2. Divisible by 4 → leap year; but if also divisible by 100 → not a leap year; but if also divisible by 400 → a leap year again. 1900 is not a leap year (divisible by 4 and 100, not by 400). 2000 is (divisible by all three).
3. a. An `if / else if` chain runs only the first branch whose condition is `true`. Reaching the second branch means the first condition, `num % 4 !== 0`, was `false`, so `num` is already known to be divisible by 4.
   b. Reaching the last branch means `num % 400 !== 0` was `false`, so `num % 400 === 0` must be `true`; checking it again changes nothing. A plain `else` also guarantees that every path returns a value.

┄┄┄┄┄┄┄┄

1. `num % 4 === 0`。`%` 返回除法之后的余数，"能整除"就是余数为 `0`。
2. 能被 4 整除 → 是闰年；但如果还能被 100 整除 → 不是；但如果还能被 400 整除 → 又是。1900 年不是闰年（能被 4 和 100 整除，不能被 400 整除）；2000 年是（三个都能整除）。
3. a. `if / else if` 链只执行第一个条件为 `true` 的分支。能走到第二个分支，说明第一个条件 `num % 4 !== 0` 是 `false`，也就是已经确定 `num` 能被 4 整除。
   b. 能走到最后一个分支，说明 `num % 400 !== 0` 是 `false`，那 `num % 400 === 0` 一定是 `true`，再判断一遍不会改变结果。直接写 `else` 还保证了每条路都有返回值。
