## W17D5 总结（11/13）

**一、冷启动**

1. 函数里的 `console.log` 在**调用的那一刻**就打印。`const b = shout("hey");` 这一行就调用了 `shout`，`HEY` 当场打出来，排在后面的 `console.log(a)` 之前。喊是在调用时喊，递出去的值要等别人去打印。
2. `if` 块里用 `let` 声明的同名变量，只活在那对花括号里。块外面的 `return label` 看见的是最外层的 `"outer"`。

**二、复习页新见到的两种写法**

1. **匿名函数**：`const multiply = function (a, b) { return a * b; };` 就是没有名字的 `function`，装进变量里，用变量名调用：`multiply(4, 5)`。箭头函数本身也是匿名函数。
2. **单个形参可以省括号**：`x => x * x * x` 等于 `(x) => x * x * x`。没有形参要写 `()`，两个以上要写 `(a, b)`，省了会报 `SyntaxError`。

**三、测验 ✅（函数模块 38/38 全部完成）**

1. **形参 vs 实参，看位置**：写在函数定义括号里的名字是形参（`a`、`b`），写在调用括号里的值是实参（`1`、`2`）。调用时实参按顺序装进形参。
2. **只有箭头函数能省花括号**，而且只在函数体是一个表达式时，连 `return` 一起省。`function` 写的普通函数省掉花括号会报 `SyntaxError: Unexpected token 'return'`，整个文件一行都跑不起来。

**四、三种"备胎"写法，门从窄到宽**

| 传进去的值 | `name = "Guest"` | `name ?? "Guest"` | `name \|\| "Guest"` |
|---|---|---|---|
| `undefined` | `"Guest"` | `"Guest"` | `"Guest"` |
| `null` | `null` | `"Guest"` | `"Guest"` |
| `""` / `0` | 原样 | 原样 | `"Guest"` |

默认参数只拦 `undefined`；`??` 拦 `undefined` 和 `null`；`||` 拦所有 falsy。默认参数那张卡的第 2 部分已经削成只考默认参数。

**卡 1**

正面：
```javascript
function add(a, b) {
  return a + b;
}

```
1. Which are the parameters, and which are the arguments?
2. How do you tell parameters and arguments apart?

┄┄┄┄┄┄┄┄

1. 哪些是形参，哪些是实参？
2. 怎么区分形参和实参？

背面：
1. Parameters: `a` and `b`. Arguments: `1` and `2`.
2. By where they appear. Names written in the parentheses of the function definition are parameters; values written in the parentheses of a function call are arguments. When the function is called, the arguments are put into the parameters in order: `a` gets `1`, `b` gets `2`.

┄┄┄┄┄┄┄┄

1. 形参：`a` 和 `b`。实参：`1` 和 `2`。
2. 看位置。写在函数定义括号里的名字是形参；写在函数调用括号里的值是实参。调用时，实参按顺序装进形参：`a` 拿到 `1`，`b` 拿到 `2`。

```javascript
function double(n) return n * 2;

const multiply = function (a, b) {

```
1. What happens when the line with `double` runs? Which kind of function can leave out the curly braces, and when?
2. `multiply` is created with an anonymous function.

   b. How do you call it?
3. `cube` has no parentheses around `x`.
   a. Is it the same as `(x) => x * x * x`?
   b. When can the parentheses around the parameters be left out?

┄┄┄┄┄┄┄┄

1. 运行 `double` 那一行会发生什么？哪种函数可以省掉花括号，什么时候能省？
2. `multiply` 是用匿名函数创建的。
   a. 什么是匿名函数？
   b. 怎么调用它？
3. `cube` 的 `x` 外面没有括号。
   a. 它和 `(x) => x * x * x` 一样吗？

背面：
1. `SyntaxError: Unexpected token 'return'`, and the file doesn't run at all. Only an arrow function can leave out the curly braces, and only when its body is a single expression; `return` is then left out too: `n => n * 2`. A function written with the `function` keyword always needs curly braces.
2. a. A function without a name. Here it is stored in the variable `multiply`. Arrow functions are anonymous too.
   b. Through the variable name: `multiply(4, 5)` returns `20`.
3. a. Yes.
   b. Only when there is exactly one parameter. With no parameters write `()`; with two or more write `(a, b)`. Leaving them out is a `SyntaxError`.

2. a. 没有名字的函数。这里它被装进了变量 `multiply`。箭头函数也是匿名函数。
