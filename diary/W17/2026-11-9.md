## 一、冷启动补丁：`toFixed()`

- `toFixed()` 返回的是**字符串**，末尾的 0 只存在于这个字符串里。
- 数字本身不带格式：`4.00` 和 `4` 是同一个值。所以 `"4.00" * 2` 得到的是 `8`，不是 `8.00`。
- 口诀：**先算数，最后才 `toFixed()`**。

## 二、函数基础（讲座 1）

**1. 声明和调用**

- `function f() { ... }` 叫声明，只是把菜谱写下来，什么都不执行。
- `f()` 叫调用，这时函数体才真正执行。
- 调用写在哪一行，就在哪一行执行。`let x = f();` 也一样：等号右边先算，函数在这一行就跑了。
- 口诀：**有括号才开跑**。

**2. 形参和实参**

- 形参（parameter）是定义函数时写的占位符，比如 `function greet(name)` 里的 `name`。
- 实参（argument）是调用时真正传进去的值，比如 `greet("Anna")` 里的 `"Anna"`。
- 少传实参，对应的形参就是 `undefined`：`greet()` 打印 `Hello, undefined!`。
- 多传的实参会被忽略：`calculateSum(1, 2, 3)` 得到 `3`。

**3. 返回值（今天的重点）**

- 打印和返回是两件独立的事：
  - `console.log` 是"喊出来"，显示在屏幕上，调用的地方什么都拿不到。
  - `return` 是"递回来"，把值交给调用的地方。
- 没写 `return`，函数就返回 `undefined`。
- 调用的位置会被换成返回值：`calculateSum(3, 4) * 2` 先变成 `7 * 2`。
- 返回值没人接（没存、没打印、没拿去算），就直接丢掉。所以单独写一行 `calculateSum(2, 11);` 什么都不显示。
- `return` 返回值的同时会立刻结束函数，写在它后面的代码永远不执行。
- `console.log` 本身也是函数，它的返回值是 `undefined`。
- 什么时候写 `return`：调用的地方需要拿结果继续用时就写。fCC 的 lab 说"返回"，就一定要用 `return`，不能用 `console.log`。
- 口诀：**打印是喊，返回是递；`return` = 交值 + 下班**。

**4. 匿名函数**

- 没有名字的函数，存进一个变量里用：`const sum = function (a, b) { return a + b; };`
- 调用方式和普通函数一样：`sum(3, 4)`。

**5. 默认参数**

- 写法：`function greetings(name = "Guest") { ... }`
- 只有形参的值是 `undefined` 时才用默认值，也就是没传实参，或者明确传了 `undefined`。

和上周学的两个"兜底"放在一起比，严格程度从宽到严：

| 写法 | 什么时候用默认值 |
|---|---|
| `\|\|` | 任何 falsy 值（`0`、`""`、`null`、`undefined` 等） |
| `??` | `null` 或 `undefined` |
| 默认参数 | 只有 `undefined` |

## 三、箭头函数（讲座 2）

**1. 它是什么**

普通函数的缩写版，没有新功能。`=>` 读作"拿到……就交出……"。

**2. 三步瘦身**

| 步骤 | 写法 | 规则 |
|---|---|---|
| 原版 | `function double(n) { return n * 2; }` | |
| ① 改箭头 | `const double = (n) => { return n * 2; };` | 删掉 `function`，存进 `const`，参数后面加 `=>` |
| ② 省圆括号 | `const double = n => { return n * 2; };` | 只有 1 个参数（且没有默认值）时才能省；0 个或 2 个以上参数必须写 |
| ③ 省花括号 | `const double = n => n * 2;` | 函数体只有一个要返回的值时，花括号和 `return` **一起删**，自动返回（隐式返回） |

**3. 两个陷阱（都出在"只删一半"）**

- 删了花括号、还留着 `return`：报错 `SyntaxError: Unexpected token 'return'`。
- 留着花括号、删了 `return`：不报错，但返回 `undefined`。

**4. 其他要点**

- 这些省略只有箭头函数能用，`function` 写法的括号一个都不能省。
- 你自己写代码的规矩：圆括号永远留着，只用两种形态：
  - 多行：`(参数) => { ...; return 值; }`
  - 一行：`(参数) => 值`

口诀：**一个参数可省圆括号，一个值可省花括号（连同 `return` 一起删）**。

## 四、作用域（讲座 3，已读，明天做实验）

作用域指的是：一个变量在代码的哪些地方能被访问。

| 类型 | 在哪声明 | 在哪能用 |
|---|---|---|
| 全局作用域 | 最外层 | 任何地方，包括函数里、块里 |
| 局部作用域 | 函数里 | 只在这个函数里 |
| 块级作用域 | `{}` 里用 `let` / `const` 声明（`if`、循环等） | 只在这对 `{}` 里 |

- 在外面访问里面的变量，会报 `ReferenceError: xxx is not defined`。
- 全局变量要少用，容易重名冲突，代码也难维护。
- 口诀：**里面能看外面，外面看不见里面**。

**卡 1**

正面：
```javascript
function doSomething() {
  console.log("Doing something...");
}

let result = doSomething();
console.log(result);
```
1. During which line does the function body run: the `function` declaration, or `let result = doSomething();`?
2. What is the value of `result`, and why?
3. Must every function contain `return`?

┄┄┄┄┄┄┄┄

1. 函数体是在哪一行执行的：`function` 声明那几行，还是 `let result = doSomething();`？
2. `result` 的值是什么？为什么？
3. 每个函数都必须写 `return` 吗？

背面：
1. During `let result = doSomething();`. The declaration only defines the function; the `()` calls it. To get a value to store in `result`, JavaScript first runs the function body, which prints `Doing something...`.
2. `undefined`. Printing to the screen is not returning a value. The function has no `return`, so it returns the default value `undefined`.
3. No. Write `return` when the caller needs the result to store, print or calculate with. A function that only does something, such as printing, can leave it out. fCC lab tests check the returned value, so when a task says "return", use `return`, not `console.log`.

┄┄┄┄┄┄┄┄

1. 在 `let result = doSomething();` 这一行。声明那几行只是定义函数，`()` 才是调用。为了拿到一个值存进 `result`，JavaScript 先把函数体跑一遍，于是打印出 `Doing something...`。
2. `undefined`。打印到屏幕上不等于返回一个值。这个函数没有 `return`，所以返回默认值 `undefined`。
3. 不是。调用的地方需要拿结果去存、打印或接着算时，才写 `return`。只负责做件事（比如打印）的函数可以不写。fCC lab 的测试检查的是返回值，所以题目说"返回"，就要用 `return`，不能用 `console.log`。
