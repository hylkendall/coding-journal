**数据类型（2 课）**
JS 是动态类型语言：类型属于值，不属于变量。声明变量时不写类型，同一个变量之后可以装另一种类型的值。Java、C# 这类静态类型语言则是在声明时就把变量的类型定死。`typeof` 返回一个表示类型名的字符串，但 `typeof null` 返回的是 `"object"`。这是 JS 最早版本留下的 bug，为了兼容旧代码一直没改。

**复习**
对象（object）是键值对的集合，键（key）就是属性名，值（value）就是属性值。符号（symbol）是独一无二且不可变的值，用 `Symbol("描述")` 创建，哪怕描述相同，两个符号也不相等。

**测验三道疑问题**

**卡 1**
正面：
What is the difference between a SyntaxError and a TypeError?
┄┄┄┄┄┄┄┄
SyntaxError 和 TypeError 有什么区别？

背面：
SyntaxError: the code breaks JavaScript's syntax rules (e.g. declaring the same `let` variable twice, or two values side by side with no `+`). TypeError: the code is written correctly, but while running, a value is used in a way it doesn't support (e.g. reassigning a `const`, or calling a string as a function).
┄┄┄┄┄┄┄┄
SyntaxError：代码写法本身不符合 JS 的语法规则（例：同一个 `let` 变量声明两次；两个值挨着放、中间没有 `+`）。TypeError：写法没问题，但运行时拿某个值做了它不支持的事（例：给 `const` 重新赋值；把字符串当函数调用）。

标签：`js::errors`

**卡 7**
正面：
JavaScript is dynamically typed. What does that mean, and why is `public Int x;` not valid JavaScript?
┄┄┄┄┄┄┄┄
JavaScript 是动态类型语言，这是什么意思？为什么 `public Int x;` 不是合法的 JS？

背面：
Types belong to values, not to variables. You don't write a type when declaring, and the same variable can later hold a value of a different type (`let x = 5; x = "hi";` is allowed). `public Int x;` puts a type in front of the variable name, which is the style of statically typed languages like Java or C#; in JavaScript it is a SyntaxError.
┄┄┄┄┄┄┄┄
类型属于值，不属于变量。声明时不写类型，同一个变量之后可以装另一种类型的值（`let x = 5; x = "hi";` 是允许的）。`public Int x;` 在变量名前写类型，这是 Java、C# 这类静态类型语言的写法，在 JS 里会报 SyntaxError。

标签：`js::data-types`
