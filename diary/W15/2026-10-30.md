### 数字和算术操作符（理论）

**1. Number 类型**
整数、小数、负数都是同一种类型 `number`。`1 / 0` 得到 `Infinity`。拿不是数字的东西做数学运算得到 `NaN`（Not a Number），而 `typeof NaN` 居然也是 `"number"`。

**2. 算术运算符**
`+` `-` `*` `/`，再加上取余 `%`（`7 % 2` 是 `1`）和乘方 `**`（`2 ** 4` 是 `16`）。除以 0 得到 `Infinity`。

**3. 数字和字符串混在一起算（类型强制转换 type coercion）**
先看 `+` 的两边有没有字符串。有字符串，`+` 就是拼接，另一边照字面变成文字：`"6" + 2` 是 `"62"`，`"Hi" + null` 是 `"Hinull"`。其他运算符（`-` `*` `/` 等）会把字符串转成数字：`"6" - 2` 是 `4`，`"6" * "2"` 是 `12`，转不成数字的就是 `NaN`。只有在数学运算里才这样换算：`true` 当 1、`false` 当 0、`null` 当 0、`undefined` 当 `NaN`。`NaN` 参与运算，结果还是 `NaN`，`"abc" * 0` 也是 `NaN`。

**实验里钉死的一点**：`"Hi" + null` 不是 `"Hi0"`。"`null` 当 0"只管数学运算，拼接时不用。

### 操作符行为学习（理论）

**4. 运算符优先级和结合性**
`*` `/` 先于 `+` `-`，`2 + 3 * 4` 是 `14`。括号里的永远先算，`(2 + 3) * 4` 是 `20`。优先级相同时看结合性（associativity）：大多数运算符从左往右，所以 `1 + 2 + "3"` 是 `"33"`，`"1" + 2 + 3` 是 `"123"`。`=` 和 `**` 从右往左：`a = b = 5` 先给 `b` 赋值；`2 ** 3 ** 2` 先算 `3 ** 2`，结果是 `512`。

**5. 自增和自减：`++` / `--`**
`a++` 和 `++a` 都会把 `a` 加 1，区别只在交出去的值：前缀 `++a` 交出加完之后的新值，后缀 `a++` 交出加之前的旧值。只有在同一句里用到这个值时才有区别，比如 `let d = c++;` 里 `d` 是旧值 5，`c` 是 6。`a++;` 单独写一行时，前后置没有区别。后缀的典型用法是取号机：`const myTicket = counter++;`。习惯上 `x++` 单独写一行，不在表达式里用它交出来的值。

**6. 复合赋值运算符**
`x 运算符= y` 就是 `x = x 运算符 y`：`+=` `-=` `*=` `/=` `%=` `**=` 都是这个套路。`&=` 和 `|=` 也一样，只是 `&`、`|` 本身是按位运算，以后再学。
