**二、数组基础（讲解 6 节 + 购物清单 workshop）**

1. `.length`：点前面是什么就数什么。字符串数字符，数组数元素；`fruits[0].length` 先取出元素，再数字符。
2. 解构：`let [a, b] = arr` 按位置取值。`...rest` 收走剩下的全部，**必须放最后**。放中间不是被忽略，而是 `SyntaxError`，整个文件一行都不跑。
3. 在 fCC 小编辑器里做实验，先点 ⊘ 清空再运行。碰到语法错误它可能不显示红字，旧输出会骗人。

**三、改原数组 vs 返回新值**

1. 字符串改不了：方法只返回新字符串，要自己接住，比如 `name = name.toUpperCase()`。
2. 数组能改：`push`、`pop`、`shift`、`unshift` 直接改原数组，不用赋值。
3. 返回值：放东西（`push`、`unshift`）返回新长度；拿东西（`pop`、`shift`）返回拿出来的那个元素。
4. 不要写 `arr = arr.push(x)`，`arr` 会变成一个数字。要用拿出来的元素，就用新变量接：`const removed = arr.pop();`
5. `const` 声明的数组照样能 `push`：`const` 只禁止换成另一个数组，不管里面装什么。

**四、午餐选择器 lab ✅（18 项全过）**

1. `"文字" + 数组`：数组会变成用逗号连接、不带空格的字符串。要逗号加空格，用 `arr.join(", ")`。
2. **`return X` = 停下来 + 交出 X**。`console.log(...)` 自己的返回值是 `undefined`，所以 `return console.log(...)` 交出去的是 `undefined`。
3. 提前结束的 `if` 里做两件事，分两行写：`console.log(...)` 负责打印，`return arr;` 或 `return;` 负责停下来。
4. 删掉 `return`，代码会继续往下走，对空数组 `pop` 得到 `undefined`，多打出一句错话。
5. 随机下标：`Math.floor(arr.length * Math.random())`，范围是 `0` 到 `length - 1`。
6. VS Code 里的 `(0) []` 是长度为 0 的空数组。

**卡 1**

正面：
```javascript
let count = 0;

function tick(step) {
  let count = step;
  count = count + 1;
  return count;
}

function tock() {
  count = count + 10;
  return count;
}

console.log(tick(1));
console.log(tock());
console.log(tick(1));
console.log(tock());
```
1. What do the four lines print?
2. Why does the second `tick(1)` print the same number as the first one?
3. Why does `tock()` print a bigger number each time?

┄┄┄┄┄┄┄┄

1. 四行分别打印什么？
2. 为什么第二次 `tick(1)` 打印的数和第一次一样？
3. 为什么 `tock()` 每次打印的数都更大？

背面：
1. `2`, `10`, `2`, `20`.
2. Every call runs the function from the first line again. `let count = step;` creates a new `count` each time, and it is thrown away when the call ends, so nothing is left over from the previous call. `count = count + 1;` has no `let`, so it changes the nearest `count`: the new one inside `tick`.
3. `tock` has no `let`, so it changes the global `count`. The global variable lives outside the function, so it keeps its value between calls: `0 → 10 → 20`.

┄┄┄┄┄┄┄┄

1. `2`、`10`、`2`、`20`。
2. 每次调用，函数都从第一行重新执行。`let count = step;` 每次都新建一个 `count`，调用结束就扔掉，上一次调用什么都没留下。`count = count + 1;` 没有 `let`，改的是离得最近的 `count`，也就是 `tick` 里这个新建的。
3. `tock` 里没有 `let`，改的是全局的 `count`。全局变量在函数外面，多次调用之间会保留它的值：`0 → 10 → 20`。

标签：`js::functions js::scope`

**卡 2**

正面：
```javascript
let name = "kendall";
name.toUpperCase();
console.log(name);

fruits.push("banana");
console.log(fruits);
```

1. What does each `console.log` print?

   b. `fruits`
   c. `arr`
2. What do these array methods return?

3. `fruits` is declared with `const`. Why can you still call `push` on it?

┄┄┄┄┄┄┄┄

1. 每个 `console.log` 分别打印什么？
   a. `name`
   b. `fruits`
   c. `arr`
2. 下面这些数组方法分别返回什么？
   a. `push` 和 `unshift`
   b. `pop` 和 `shift`
3. `fruits` 是用 `const` 声明的，为什么还能对它调用 `push`？

背面：
1. a. `kendall`. String methods never change the original string. They return a new string, which you have to store yourself.
   b. `["apple", "banana"]`. `push`, `pop`, `shift` and `unshift` change the original array directly, so no assignment is needed.
   c. `2`. `push` returns the new length, and `=` stores that number in `arr`, so the array is lost. Never write `arr = arr.push(...)`.
2. a. The new length of the array. (When adding, you already have the item, so you get the length.)
   b. The element that was removed. (When removing, the item has to be handed to you.)
3. `const` only forbids reassigning the variable to a different value, such as another array. It does not stop the contents of the array from changing.

┄┄┄┄┄┄┄┄

1. a. `kendall`。字符串方法不会改原来的字符串，只返回一个新的，要自己存起来。
   b. `["apple", "banana"]`。`push`、`pop`、`shift`、`unshift` 直接改原数组，不需要赋值。
   c. `2`。`push` 返回新长度，`=` 把这个数存进了 `arr`，原来的数组就丢了。不要写 `arr = arr.push(...)`。
2. a. 改完后数组的长度。（放东西：东西本来就在你手里，所以告诉你长度。）
   b. 被拿出来的那个元素。（拿东西：拿出来的东西要交到你手上。）
3. `const` 只禁止把这个变量重新赋值成别的值，比如另一个数组；不管数组里面的内容怎么变。

标签：`js::arrays js::strings`

**卡 3**

正面：
```javascript
let fruits = ["apple", "banana", "orange", "grape"];
let [first, ...rest, last] = fruits;
console.log(first, rest, last);
```
1. What happens when this code runs?
2. Where must `...rest` be placed in a destructuring pattern? Why?
3. If line 2 is changed to `let [first, second, ...rest] = fruits;`, what are `first`, `second` and `rest`?

┄┄┄┄┄┄┄┄

1. 运行这段代码会发生什么？
2. 在解构里，`...rest` 必须放在哪里？为什么？
3. 如果第 2 行改成 `let [first, second, ...rest] = fruits;`，`first`、`second`、`rest` 分别是什么？

背面：
1. `SyntaxError: Rest element must be last element`. The whole file is rejected, so not a single line runs, not even the lines before it. `...rest` in the middle is not ignored.
2. It must be the last element. `...rest` means "take everything that is left", so nothing would remain for a variable after it. JS forbids this instead of guessing.
3. `first` is `"apple"`, `second` is `"banana"`, `rest` is `["orange", "grape"]`.

┄┄┄┄┄┄┄┄

1. `SyntaxError: Rest element must be last element`。整个文件被拒绝，一行都不运行，连它前面的行也不运行。`...rest` 放在中间不是被忽略。
2. 必须放在最后一个。`...rest` 的意思是"剩下的全给我"，它后面的变量什么都拿不到。JS 不去猜，直接不允许这么写。
3. `first` 是 `"apple"`，`second` 是 `"banana"`，`rest` 是 `["orange", "grape"]`。

标签：`js::arrays`

**卡 5**

正面：
```javascript
function removeLastLunch(arr) {
  if (arr.length === 0) {
    return console.log("No lunches to remove.");
  }
  const removed = arr.pop();
  console.log(`${removed} removed from the end of the lunch menu.`);
  return arr;
}
```
1. What does `removeLastLunch([])` print, and what does it return? Why?
2. If only the word `return` is deleted from the `if` block, what does `removeLastLunch([])` print?
3. How should the `if` block be written so that it prints the message and returns the array?

┄┄┄┄┄┄┄┄

1. `removeLastLunch([])` 打印什么、返回什么？为什么？
2. 如果只把 `if` 块里的 `return` 这个词删掉，`removeLastLunch([])` 会打印什么？
3. `if` 块应该怎么写，才能既打印提示，又返回数组？

背面：
1. It prints `No lunches to remove.` and returns `undefined`. `return X` stops the function and hands over X. Here X is `console.log(...)`, and `console.log` itself returns `undefined`.
2. Two lines: `No lunches to remove.` and `undefined removed from the end of the lunch menu.` Without `return`, the function does not stop, and `pop()` on an empty array gives `undefined`.
3. Two separate lines inside the `if`: `console.log("No lunches to remove.");`, then `return arr;`. `console.log` prints; `return arr` stops the function and hands over the array.

┄┄┄┄┄┄┄┄

1. 打印 `No lunches to remove.`，返回 `undefined`。`return X` 让函数停下来并交出 X。这里的 X 是 `console.log(...)`，而 `console.log` 自己的返回值是 `undefined`。
2. 两行：`No lunches to remove.` 和 `undefined removed from the end of the lunch menu.`。没有 `return`，函数不会停，对空数组 `pop()` 得到 `undefined`。
3. `if` 里分两行写：先 `console.log("No lunches to remove.");`，再 `return arr;`。`console.log` 负责打印，`return arr` 负责让函数停下来并交出数组。

标签：`js::functions js::arrays`






"不 return 不放心"很正常，给你一条判断：**看调用的人要不要拿到一个结果**。

- 要：`return` 那个结果。fCC 题目里写了 "Return ..." 就是信号，两个 remove 函数写了，所以要 `return arr`
- 不要，函数的活就是打印：不用写。走到最后的 `}` 函数自己就结束，自动交出 `undefined`。`getRandomLunch` 和 `showLunchMenu` 就是这种
- 中途要停：写 `return;`，要交结果的就写 `return 结果;`
