**一、方法的返回值 vs 函数的返回值**

1. 方法的返回值交给调用它的那一行。`arr.push(item);` 返回的 2 没有人接，就被扔掉了。
2. 调用函数得到什么，只看函数里的 `return`，没写 `return` 就是 `undefined`。
3. 想把方法的返回值交出去，要写 `return arr.push(item);`。
4. 数组传进函数，形参和外面的变量是同一个数组，函数里 `push` 改的就是外面那个。

**二、`=` 不复制（复习）**

1. 数一数造了几个数组：`[1, 2]` 这样的字面量会造，`[...a]` 会造，`=` 不会造。
2. `const b = a;` 以后，`b` 只是同一个数组的另一个名字。

**三、`join` 的细节**

1. 结果是**一个**字符串，`["b", "c", "d"].join()` 得到 `"b,c,d"`。
2. 不传参数时只加逗号，不加空格。要逗号加空格就写 `join(", ")`。
3. `console.log` 打印字符串时不显示两头的引号，屏幕上看到的是 `b,c,d`。
4. fCC 复习页说不传分隔符就什么都不加，那是错的。

**四、改不改原数组**

1. `reverse()` 把整个原数组倒过来，一个元素都不会少。
2. `slice()` 只把一部分抄进新数组，原数组不变，也不会删掉任何东西。
3. 函数里想 `reverse` 又不想动到原数组：先 `const result = [...list];` 再倒。
4. `indexOf` 只返回第一个匹配的位置，而且分大小写，`"Apple"` 和 `"apple"` 算两个不同的值。

**五、变量一定要声明**

1. `re = ...` 没写 `let` 或 `const`，在 Node 里能跑，是因为 JS 会悄悄建一个全局变量。
2. 在更严格的环境（严格模式，还没教）里，这行会报 `ReferenceError: re is not defined`。
3. 规则：变量第一次出现，一定用 `let` 或 `const`。只用一次的值，直接 `return` 出去就行，不用存进变量。

**六、从 `splice` 里取出被删的元素**

1. 只删一个，`splice` 返回的也是数组：`["Rain"]`。
2. 要拿到字符串 `"Rain"`：写 `list.splice(index, 1)[0]`，或者 `const [removed] = list.splice(index, 1);`。
3. `.join()` 也能得到 `"Rain"`，但它本来是"拼起来"的意思，读的人看不出你的意图。

**七、写代码的小习惯**

1. 同一个 `indexOf` 要用两次，就先存进 `const index`，后面都用它。
2. 函数最后一行执行完会自己结束，不需要写 `return;`。
3. 要在输出里带双引号，直接写进反引号就行：`` `"${song}" added.` ``。
4. 写函数之前先写三行注释：输入、有几种情况、每种情况打印什么或返回什么。

**八、fCC 中文版的用词**

- 复习页里"数组在内存中连续存放"那句不用管。

**卡 1**

正面：
```javascript
function addItem(arr, item) {
  arr.push(item);
}

const list = ["a"];
const result = addItem(list, "b");
```
1. What are `result` and `list` now?
2. Why does `list` change, even though the function only uses `arr`?
3. `arr.push(item)` returns `2`. Why isn't `result` equal to `2`?
4. How do you change `addItem` so that `result` is `2`?

┄┄┄┄┄┄┄┄

1. 现在 `result` 和 `list` 分别是什么？
2. 函数里只用了 `arr`，为什么 `list` 会变？
3. `arr.push(item)` 返回的是 `2`，为什么 `result` 不是 `2`？
4. 怎么改 `addItem`，才能让 `result` 是 `2`？

背面：
1. `result` is `undefined`. `list` is `["a", "b"]`.
2. `arr` and `list` are the same array. Passing an array into a function passes a reference to it, just like `=`.
3. `push` hands its return value back to the line that called it, `arr.push(item);`, and nothing uses it there. What a function call returns depends only on the function's own `return`. `addItem` has no `return`, so it returns `undefined`.
4. `return arr.push(item);`

┄┄┄┄┄┄┄┄

1. `result` 是 `undefined`，`list` 是 `["a", "b"]`。
2. `arr` 和 `list` 是同一个数组。把数组传进函数，传的是指向它的引用，和 `=` 一样。
3. `push` 的返回值交给了调用它的那一行 `arr.push(item);`，那一行没有用它。调用函数得到什么，只看函数自己的 `return`。`addItem` 没写 `return`，所以返回 `undefined`。
4. `return arr.push(item);`

1. What do the two `console.log` lines print?
2. Which line breaks the rule "don't change the original array"? How do you fix it?

┄┄┄┄┄┄┄┄

（代码注释：目标是倒序返回最后两个元素，并且不改动原数组。）

2. 哪一行违反了"不改动原数组"？怎么改？
