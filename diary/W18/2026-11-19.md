## W18D4 今日总结（11/19）

**一、块级作用域（复习）**

1. `let` 写在哪个 `{}` 里，变量就只存在于那个块里，出了 `}` 就没了。if 后面的 `{}` 和 else 后面的 `{}` 各算一个块。
2. 出了块还用这个名字：外面有同名变量，就用外面那个；外面没有，就报 `ReferenceError: ... is not defined`。
3. 想在 if / else 之后接着用：在外面写一次 `let msg;`，块里只赋值，不再写 `let`。

**二、浅拷贝（修正版，替换昨天"数中括号"那条）**

1. 浅拷贝只新建最外面一层。里面装的数组不管藏得多深，第 2 层、第 3 层……都还是原来那些，两边共用。
2. 怎么判断：
   - 改的是 copy 自己，比如 `copy.push(x)`、`copy.splice(...)`、`copy[1] = x`：原数组不变。
   - 改的是 copy 里面装的数组，比如 `copy[0].push(x)`、`copy[0][1] = x`、`copy[0][0].push(x)`：原数组跟着变。
3. 昨天那条"数中括号有几层"不完整。`copy[0].push(8)` 只有一层中括号，改的却是里面的小数组。
4. 用途：改一个数组，又不想动到原来那个。比如函数里先写 `const result = [...arr];`，或者 `[...nums].reverse()`。数组里只有数字、字符串时，复制出来就是完全独立的一份。
5. 每一层都复制叫"深拷贝"，还没学。

**三、`=` 和引用：原始类型 vs 非原始类型（第 5 节）**

1. 原始类型有 7 种：number、bigint、string、boolean、null、undefined、symbol。每个只表示一个值，都不是对象。fCC 中文版有时叫"原语"或"原生"类型。
2. 原始值本身不能改（immutable），但变量可以重新赋值。
3. 变量里放的是什么：
   - 原始类型：放的是值本身。`=` 复制这个值，两个变量互不影响。
   - 非原始类型（普通对象、数组、函数）：放的是引用，也就是这个对象在内存里的位置。`=` 复制的是引用，两个名字指向同一个对象。
4. `=` 不会新建任何东西，浅拷贝至少会新建外层。这两条对数组和对象完全一样。对象的浅拷贝写成 `{ ...obj }`，还没正式教。
5. 只有直接写 `[1, 2]` 这样的字面量才会新建数组。`[inner, inner]` 放进去的是已有数组的引用，所以两格是同一个数组。

**四、"几乎一切都是对象"（第 1 节）**

1. 数组和函数本身就是对象，`typeof [1, 2]` 是 `"object"`。`arr.length`、`arr.push()` 用的就是对象的点号写法。
2. 字符串和数字不是对象。你在后面加点时，JS 会临时把它包成一个对象，用完就扔，所以 `"hello".length` 能用。
3. `null` 和 `undefined` 没有对应的包装，后面加点会报 `TypeError: Cannot read properties of null`。

**五、创建对象、读属性（第 1、4 节）**

1. 对象由一组属性组成。每个属性写成"名字（key）: 值"，属性之间用逗号隔开，比如 `{ name: "Alice", age: 30 }`。值也可以是数组或另一个对象。
2. 点号 `obj.name` 最常用，前提是属性名是合法标识符：不以数字开头，不含空格和特殊字符。
3. 方括号 `obj["name"]` 会先把括号里的东西算一遍：
   - 属性名带空格或以数字开头时，定义时要加引号，读取时只能用方括号，比如 `oddObject["property with spaces"]`。
   - 属性名存在变量里时写 `person[propertyName]`。点号做不到：`person.propertyName` 找的是名字就叫 `propertyName` 的属性。
   - 不加引号写成 `person[contact]`，`contact` 会被当成变量，没有这个变量就报 `ReferenceError`。
4. 对象套对象时，一层层往下接：`person.contact.phone.work`，或者 `person["contact"]["phone"]["work"]`。
5. 对象里有数组时，数组用索引，对象用属性名，混着接：`person.addresses[1].city`。

**六、删除属性（第 2 节）**

1. `delete person.job;` 直接从原对象上删掉这个属性，之后读 `person.job` 得到 `undefined`。
2. 解构加 rest：`const { job, city, ...rest } = person;` 不删任何东西。`rest` 是一个不含 job 和 city 的新对象，`person` 本身不变。
3. 对象解构的规则：
   - 左边用 `{ }`，照着右边的形状写。
   - 按属性名对应，跟顺序无关。
   - 名字写错了，拿到的是 `undefined`，不会报错。
   - rest 只能放在最后，否则报 `SyntaxError`。对象的 rest 收集出来是一个新对象。
   - 完整内容在模块 5 后面的"可选链和对象解构"讲解里。

**七、检查对象有没有某个属性（第 3 节）**

1. `obj.hasOwnProperty("name")`，返回 true 或 false。
2. `Object.hasOwn(obj, "name")`，现在推荐用这个，相当于 hasOwnProperty 的升级版。参数顺序是先对象，后属性名。
3. `"name" in obj`，属性名写在左边，是个字符串。
4. `obj.name !== undefined` 也能用，但如果属性存在、值正好是 `undefined`，会被误判成"没有"。
5. 前三种只看属性在不在，不看值是什么。不要用 `if (user.score)` 来判断属性存不存在：score 是 `0` 时，它是 falsy，if 里的代码不会执行。
6. 钩子：课里说 hasOwn 只认"自己身上的"属性，不算"继承来的"。继承到模块 21「类和 this」才讲。现在只记一句：`"toString" in {}` 是 true，`Object.hasOwn({}, "toString")` 是 false。

**八、函数 vs 对象方法（第 6 节）**

1. 方法就是存在对象属性里的函数，比如 `sayHello: function () { ... }`。
2. 调用方式不同：函数直接用名字调用，`greet("Alice")`；方法要在对象后面加点调用，`person.sayHello()`。
3. 用点号调用方法时，点前面那个对象就是方法里的 `this`，所以 `this.name` 读到的是 `person.name`。`this` 会在模块 21 正式学。
4. 方法用来把代码按对象组织起来，函数用来写更通用、可以到处复用的代码。

**九、`Object()` 构造函数（第 7 节）**

1. 构造函数是一种专门用来创建并初始化对象的函数，配合 `new` 调用。`new Object()` 得到一个空对象 `{}`。
2. 不加 `new`，直接传一个值进去：
   - 数字、字符串、布尔值会被包成对象，`typeof Object(42)` 是 `"object"`。
   - `null` 和 `undefined` 会得到 `{}`。
3. 它唯一说得出来的用处，是把原始值包装成对象。平时建对象都用字面量 `{}`。

3. 在 `person.sayHello()` 里，`this` 是什么？这次调用返回什么？

背面：
1. A method: a function stored as a property of an object.
2. `greet("Ann")`, by its name. `person.sayHello()`, with dot notation on the object it belongs to.
3. `this` is `person`, the object before the dot. It returns `"Hello, my name is Bob"`.

┄┄┄┄┄┄┄┄

1. 方法：存在对象属性里的函数。
2. `greet("Ann")`，直接用名字调用。`person.sayHello()`，在它所属的对象后面用点号调用。
3. `this` 是 `person`，也就是点前面的那个对象。返回 `"Hello, my name is Bob"`。
