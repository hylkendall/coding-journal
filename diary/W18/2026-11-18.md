## W18D3 总结（11/18）数组练习日

冷启动 2 题全对。练习 6 题加 1 道加分题都做完了。

**一、`splice` 取出的东西**

1. `splice` 返回的**永远是数组**，只删一个也是数组。
2. `[0]` 是从数组里**取出**元素，不是转换。元素放进去是什么类型，取出来还是什么类型。把数组变成字符串是 `join` 的事。
3. 想直接拿到被删的那个元素：`const [removed] = arr.splice(index, 1);`
4. 解构准备几个名字就接几个。多出来的没人接也不报错，但照样从原数组里删掉了。
5. 起点超出范围时什么都删不掉，返回 `[]`。对 `[]` 取 `[0]` 读的是不存在的位置，得到 `undefined`。

**二、漏写 `const` 的后果**

赋值时前面不写 `const`/`let`，JS 会悄悄建一个全局变量，函数外面也能拿到。写上 `const`，变量就关在函数里。在函数外读它会报 `ReferenceError`，这才是正常的。

**三、解构：按位置对齐来看**

1. 把左右两边按位置一一对齐，空逗号就是跳过那个位置。
2. 默认值**只在拿到 `undefined` 时**生效，位置不存在也算 `undefined`。`null` 是值，不会触发默认值。规则跟默认参数一样。
3. rest **永远给一个数组**，剩一个是 `[2]`，一个不剩是 `[]`。
4. 同样写作 `...`，方向相反：
   - 写在解构左边是 **rest（收集）**，把剩下的收进一个新数组
   - 写在 `[]` 里面是 **spread（展开）**，把元素倒出来，浅拷贝用的就是它

**四、输出格式**

1. `console.log(a, b)` 打印时参数之间是**空格**。代码里的逗号只是用来隔开参数。
2. 空数组 `join` 出来是 `""`，而 `""` 是 falsy，所以可以写 `others.join(", ") || "none"`。
3. 用 VS Code 终端跑 `node`，看到的格式跟文件里的「应打印」一样。控制台里看到的 `(0)`、`Array(2)` 是那个工具自己的显示方式。

**五、浅拷贝 + 二维数组（今天最难的点）**

1. 浅拷贝只复制最外面一层：外层数组是新的，里面的小数组是**共用**的。比方：复制了一份写着文档链接的清单，链接点开还是同一份文档。
2. **判断标准：数中括号有几层**
   - 一层 `copy[1] = ...`：改的是 copy 自己的格子，只影响 copy
   - 两层 `copy[0][0] = ...`：改的是共用的小数组里面，两边都能看到
3. `copy === grid` 是 `false`（两个外层），`copy[0] === grid[0]` 是 `true`（同一个小数组）。
4. `const list = [box];` 放进去的是 `box` 本身，不是一份副本。
5. 二维数组读写都用 `arr[行][列]`。给人看的编号从 1 开始，要先减 1 才是索引。

**六、写函数的固定写法**

1. **按值查找**：`indexOf` 只找一次，结果存进 `index`，用 `!== -1` 判断，后面直接用 `index`。不用再加 `includes`。
2. **替换**：`splice(index, 1, newItem)`。
3. **不改原数组**：第一步先复制，后面都在副本上操作。找不到时也返回副本。
4. **分情况赋值**：外面 `let` 声明一次，`if / else` 里只赋值，不要再写 `let`。
5. **数据和显示分开**：别往数据数组里塞显示用的文字，另外用一个变量放要显示的字符串。
6. 每条路都返回同一个东西时，把 `return` 放到 `if` 外面。

**七、命名和小习惯**

变量名小写开头、用驼峰（`newArr`、`rowIndex`），名字要说清楚存的是什么，别用 `a`。后面不再赋值就用 `const`。题目里的 `<row>` 是占位符，不要原样写进输出。分号保持统一。

**卡 1**

正面：
```javascript
const nums = [10, 20, 30, 40];
const box = nums.splice(1, 2);

const n = [7, 8, 9];
const [first] = n.splice(0, 2);

const one = ["a"];
const empty = one.splice(10, 1);
```
1. What are `box` and `nums` now?
2. `box[0]` is `20`. Does `[0]` convert the array into a number?
3. What are `first` and `n`? What happened to `8`?
4. What are `empty` and `empty[0]`? Why?

┄┄┄┄┄┄┄┄

1. 现在 `box` 和 `nums` 分别是什么？
2. `box[0]` 是 `20`。`[0]` 是把数组转换成了数字吗？
3. `first` 和 `n` 分别是什么？`8` 去哪了？
4. `empty` 和 `empty[0]` 分别是什么？为什么？

背面：
1. `box` is `[20, 30]`: `splice` always returns an array of the removed elements, even if only one is removed. `nums` is `[10, 40]`.
2. No. `[0]` takes the element out of the array, and the element keeps its own type (here a number). Turning an array into a string is what `join` does.
3. `first` is `7`, `n` is `[9]`. The destructuring has only one name, so it takes only the first removed element. Nobody takes `8`, but it is still removed from `n`.
4. `empty` is `[]`, `empty[0]` is `undefined`. Index 10 doesn't exist, so nothing is removed and an empty array comes back. Reading index 0 of an empty array gives `undefined`.

┄┄┄┄┄┄┄┄

1. `box` 是 `[20, 30]`：`splice` 返回的永远是被删元素组成的数组，只删一个也是数组。`nums` 是 `[10, 40]`。
2. 不是。`[0]` 是从数组里把元素取出来，元素保持自己的类型（这里是数字）。把数组变成字符串是 `join` 的事。
3. `first` 是 `7`，`n` 是 `[9]`。解构只写了一个名字，所以只接第一个被删的元素。`8` 没人接，但它照样从 `n` 里删掉了。
4. `empty` 是 `[]`，`empty[0]` 是 `undefined`。索引 10 不存在，什么都删不掉，返回空数组。读空数组的第 0 位，得到 `undefined`。

标签：`js::arrays`

**卡 3**

正面：
```javascript
const [a, b = 60, c = 50, d = 40, ...others] = [90, undefined, 75];
const [x = 1, , z = 3] = [null, 2];
const [p, ...r] = [1, 2];
```
1. What are `a`, `b`, `c`, `d` and `others`?
2. What are `x` and `z`?
3. a. What is `r`?
 b. Here `...` is rest. What does `...` do in `[...arr]`?
4. When does a default value in destructuring take effect?

┄┄┄┄┄┄┄┄

1. `a`、`b`、`c`、`d`、`others` 分别是什么？
2. `x` 和 `z` 分别是什么？
3. a. `r` 是什么？
 b. 这里的 `...` 是 rest。在 `[...arr]` 里，`...` 做的是什么？
4. 解构里的默认值什么时候生效？

背面：
1. `90`, `60`, `75`, `40`, `[]`. Line both sides up by position: `b` gets `undefined`, so its default is used. `c` gets `75`, so its default is ignored. Position 3 doesn't exist, so `d` gets `undefined` and uses its default. Nothing is left for the rest, so `others` is an empty array.
2. `null` and `3`. `null` is a value, so `x`'s default is not used. The empty slot between the commas skips `2`. `z`'s position doesn't exist, so it uses its default.
3. a. `[2]`. Rest always gives an array, even with one element left or none.
 b. It is spread: it pours the elements out into a new array, which is how a shallow copy is made. Rest collects, spread pours out.
4. Only when the value at that position is `undefined`, including when the position doesn't exist. Same rule as default parameters.

┄┄┄┄┄┄┄┄

1. `90`、`60`、`75`、`40`、`[]`。左右两边按位置对齐：`b` 拿到 `undefined`，用默认值；`c` 拿到 `75`，默认值不用；位置 3 不存在，`d` 拿到 `undefined`，用默认值；没有剩下的元素，`others` 是空数组。
2. `null` 和 `3`。`null` 是一个值，所以 `x` 的默认值不用。两个逗号中间的空位跳过了 `2`。`z` 对应的位置不存在，用默认值。
3. a. `[2]`。rest 永远给一个数组，只剩一个或一个不剩都是数组。
 b. 是 spread（展开）：把元素倒进一个新数组里，浅拷贝就是这么做的。rest 是收集，spread 是展开。
4. 只在那个位置的值是 `undefined` 时生效，位置不存在也算。规则跟默认参数一样。

标签：`js::arrays`

**卡 5**

正面：
```javascript
const grid = [[1, 2], [3, 4]];
const copy = [...grid];
copy[0][0] = 99;
copy[1] = [0, 0];
```
1. What are `grid` and `copy` now?
2. Why did `copy[0][0] = 99` change `grid`, but `copy[1] = [0, 0]` didn't?
3. What are `copy === grid` and `copy[0] === grid[0]`?

┄┄┄┄┄┄┄┄

1. 现在 `grid` 和 `copy` 分别是什么？
2. 为什么 `copy[0][0] = 99` 改到了 `grid`，而 `copy[1] = [0, 0]` 没有？
3. `copy === grid` 和 `copy[0] === grid[0]` 分别是什么？

背面：
1. `grid` is `[[99, 2], [3, 4]]`. `copy` is `[[99, 2], [0, 0]]`.
2. A shallow copy makes a new outer array, but the inner arrays are shared. Count the brackets: `copy[1] = ...` (one layer) replaces a slot in `copy`'s own outer array, which `grid` doesn't share. `copy[0][0] = ...` (two layers) changes the inside of a shared inner array, so both see it.
3. `false` (two different outer arrays) and `true` (the same inner array).

┄┄┄┄┄┄┄┄

1. `grid` 是 `[[99, 2], [3, 4]]`，`copy` 是 `[[99, 2], [0, 0]]`。
2. 浅拷贝会新建外层数组，但里面的小数组是共用的。数中括号：`copy[1] = ...`（一层）换的是 `copy` 自己外层的格子，`grid` 不共用这个；`copy[0][0] = ...`（两层）改的是共用的小数组里面，所以两边都能看到。
3. `false`（两个不同的外层数组）和 `true`（同一个小数组）。

标签：`js::arrays`

**卡 6**

正面：
1. A function should replace the first `oldItem` in `list` with `newItem`, changing `list`. What are the steps?
2. A function should remove the first `item` from `arr` but leave `arr` unchanged.
 a. What do you do first?
 b. What must you return when `item` isn't found? Why?

┄┄┄┄┄┄┄┄

1. 一个函数要把 `list` 里第一个 `oldItem` 换成 `newItem`，直接改 `list`。步骤是什么？
2. 一个函数要从 `arr` 里删掉第一个 `item`，但 `arr` 本身不能变。
 a. 第一步做什么？
 b. 找不到 `item` 时要返回什么？为什么？

背面：
1. `const index = list.indexOf(oldItem);`, then `if (index !== -1)`, then `list.splice(index, 1, newItem);`. Search only once: `-1` already means "not there", so `includes` isn't needed.
2. a. Copy it first, for example `const result = [...arr];`, then use `indexOf` and `splice` on the copy.
 b. Return the copy, not `arr`. That way the caller always gets a new array (`result === arr` is `false`), whether or not anything was removed.

┄┄┄┄┄┄┄┄

1. 先 `const index = list.indexOf(oldItem);`，再 `if (index !== -1)`，然后 `list.splice(index, 1, newItem);`。只找一次：`-1` 本身就表示"不在里面"，用不着 `includes`。
2. a. 先复制，比如 `const result = [...arr];`，再在副本上用 `indexOf` 和 `splice`。
 b. 返回副本，不是 `arr`。这样不管删没删，调用的人拿到的都是一个新数组（`result === arr` 是 `false`）。

标签：`js::arrays js::functions`
